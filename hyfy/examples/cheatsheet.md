# hyfy 快速上手卡

> 一页纸 cheatsheet。用 hyfy 之前扫一眼，5 分钟内出稿。

---

## 一、触发方式

```
"用 hyfy 帮我写个 XX 发言稿"     # 推荐：明确触发
"hyfy：写个 XX 致辞"              # 推荐：隐式触发
"写个发言稿/致辞/讲话稿"        # 自动触发
```

**不要直接说"帮我写个发言稿"** —— hyfy 会先问 5 个问题（场景/角色/听众/素材/风格）。

---

## 二、5 个必问信息

hyfy 被触发后，先回答这 5 个问题：

| # | 问题 | 备选 |
|---|---|---|
| 1 | **场景**：什么类型？时长？ | 商务会谈 / 项目推进 / 汇报 / 致辞 / 签约揭牌 / 调研接待 / 党建 / 即兴 |
| 2 | **角色**：几把手？代表单位还是个人？ | 一把手 / 副职 / 部门负责人 |
| 3 | **听众**：在场最关键的人？ | 按"上/平/下/外"分类 |
| 4 | **素材**：已确定的数字、项目、机制？ | 直接给素材或说"暂无" |
| 5 | **风格**：A / C / A+C？ | 70/30 / 90/10 / 混搭 |

**全部答齐再开写** —— 不答齐就开写 = 出套话稿。

---

## 三、6 步工作流速查

```
[1] 角色定位  → 决定语气（一把手可"讲要求"，副职只能"做表态"）
[2] 场合识别  → 决定结构（5 段式 / 3 段式 / 即兴式）
[3] 听众画像  → 决定金句投放（对上/对下/对外/全场）
[4] 核心三段  → 态度/立场 + 干货/抓手 + 表态/承诺
[5] 金句 1-3  → 嵌入正文 **加粗** 作为讲话的"重音位"
[6] 收尾收束  → 共同愿景 + 具体抓手 + 再次致谢
```

---

## 四、3 个万能金句模板

| 类型 | 模板 | 适用 |
|---|---|---|
| **对上管理** | "请 XX 放心，我们 X" | 几乎所有场景 |
| **对下担当** | "不当旁观者、不做传声筒，主动靠前、具体负责、闭环推进" | 几乎所有场景 |
| **对外姿态** | "既 X 也 Y；既尊重 X 的专业优势，也体现 X 的服务效率" | 对外合作场景 |

**金句 4 问自检**：
- 脱离上下文还能引用吗？→ 不能就不是金句
- 有具体抓手吗？→ 全是形容词就是空话
- 听者能复述给同事吗？→ 复述不出就是无效
- 会让人觉得"这正是我想说但没说出来的"吗？→ 没感觉就是没到位

## 五、3 段式 vs 5 段式速选

| 场景 | 结构 | 时长 |
|---|---|---|
| 商务会谈、项目推进表态 | **5 段式** | 5-10 分钟 |
| 工作汇报、综合表态 | **5 段式** | 10-15 分钟 |
| 接待致辞、签约揭牌 | **3 段式** | 3-5 分钟 |
| 项目推进短表态 | **3 段式** | 3 分钟 |
| 即兴讲话 | **即兴式**（"三个我"） | 3-5 分钟 |

## 六、风格速选

| 风格 | 配比 | 适用 |
|---|---|---|
| **A** | 70% 市场 + 30% 政治 | 国企/央企对接（**默认**） |
| **C** | 90% 市场 + 10% 政治 | 民营/外资/产业论坛 |
| **A+C** | 主体 A，关键金句 C | 既要专业又要政治正确 |

**首次用 hyfy 选 A**，不确定时用 A+C。

---

## 七、5 个致命踩坑

| 踩坑 | 表现 | 规避 |
|---|---|---|
| ❌ 副职写"几点要求" | 越位 | 副职只能说"做表态" |
| ❌ 全是成绩没有反思 | 听感假 | 至少一句"直面问题" |
| ❌ 时间节点写太死 | 变化风险 | 用"目标/争取/力争"等软性词 |
| ❌ 套话成串没有抓手 | 听感空 | 每段必须有一个数字/项目/机制 |
| ❌ 没有对上管理 | 听感"自嗨" | 必须"请 XX 放心"+"既 X 也 Y" |

---

## 八、合规红线（一票否决）

| 红线 | 应对 |
|---|---|
| 编造政策文件、数据、领导人原话 | **删除**或 `<待核实>` |
| 政治表述 > 30%（党建除外） | 改市场化表达 |
| 对方企业未公开信息 | **删除** |
| 排名类用词（"第一""唯一""率先"） | 改"处于第一梯队""具备领先优势" |

---

## 九、hyfy + pb 一句话流程

```
hyfy 出稿 → 加粗金句 → "建议联动 pb 排版" → pb 生成 .docx → 上传飞书云空间 → 返回链接
```

**写完不排版 = 效果减半**。

## 十一、用户偏好记录（你历次调整 hyfy 沉淀的）

| 偏好 | 来源 |
|---|---|
| ❌ 不要"大家上午好"作为固定开场 | 通号案例反馈 |
| ❌ 不要"时间节点"在干货段（6/9/12 月等） | 通号案例反馈 |
| ✅ 政治表述克制（不超过 20-30%） | 默认风格 |
| ✅ 喜欢"6% 承载 100% 属地责任"这种小比例大担当句式 | 通号案例验证 |
| ✅ 喜欢"合伙人/连接器/合伙人"三角色排比 | 通号案例验证 |

**这些偏好已沉淀到 `golden-lines.md` 和 `joint-venture.md` 的反馈记录里**。

## 十二、第一次用 hyfy 的建议流程

1. 打开 `examples/joint-venture.md`，看一遍工作流记录
2. 准备 5 个必问信息的答案
3. 触发 hyfy："用 hyfy 帮我写个 XX 发言稿"
4. 回答 hyfy 的 5 个问题
5. 看初稿，标注出"哪里要改"
6. 让 hyfy 联动 pb 排版
7. 检查 .docx，重点看加粗位（讲话重音位）
8. 反馈"哪里要改"，沉淀新偏好

**第一次 = 学习流程，第二次 = 复用，第三次 = 信任**。
