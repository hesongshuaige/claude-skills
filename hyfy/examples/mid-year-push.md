# 案例：年中工作推进会表态发言（对内场景 · 3 段式）

> 本案例为 hyfy skill 的"对内场景"参考样，演示 hyfy 在 3 段式短稿 + 对内听众上的复用能力。
> 与 `joint-venture.md`（对外商务会谈，5 段式）形成"对内 / 对外 × 短稿 / 长稿"双对照。

---

## 一、案例背景

| 维度 | 内容 |
|---|---|
| **场景** | 集团/全区年中工作推进会表态发言 |
| **时长** | 3 分钟（约 750 字） |
| **角色** | 诸葛资本公司董事长（一把手） |
| **听众** | 上：区领导、集团领导；平：兄弟单位负责人；下：本公司团队、下属公司 |
| **议题** | 上半年总结 + 下半年三项重点承诺 |
| **风格** | A（70/30 混搭，对内场景可适度加重政治表述） |
| **特殊挑战** | ① 时间短必须精炼；② 不能"只剩成绩"（要直面问题）；③ 对内场合表态要有"扛事"信号 |

---

## 二、6 步工作流记录

### Step 1：角色定位
- **角色**：诸葛资本公司董事长（一把手）
- **关键判断**：本场是"集团内部推进会"，董事长是"主要表态方"
- **姿态**：对上是"承诺者"+"执行者"；对下是"指挥员"+"扛旗人"
- **语域**：相对通号案例更"硬"——多用动词、少用形容

### Step 2：场合识别
- **场合类型**：年中工作推进会表态发言
- **时长要求**：3 分钟（约 750 字）
- **结构选择**：**3 段式**（开场+成绩 / 三项重点工作 / 表态收尾）

### Step 3：听众画像
- **对谁做对上管理**：区领导、集团领导（要让他们"放心"+"看到干劲"）
- **对谁做对下担当**：本公司团队（要让他们"看到方向"+"看到董事长带头上"）
- **对谁做对外姿态**：兄弟单位（要让他们"看到配合"+"看到担当"）
- **金句投放位**：
  - 1 句投放给上级（"请 XX 放心"+"指标不退、目标不减、干劲不松"）
  - 1 句投放给下级（"不当旁观者、不做传声筒"）
  - 1 句投放给全场（"时间过半、任务过半，但发展不能过半"）

### Step 4：核心三段
- **第一段（成绩回顾）**：1 句话定位 + 1 句金句（"时间过半、任务过半，但发展不能过半"）
- **第二段（三项重点工作）**：
  - 节奏往前赶（机制+具体抓手）
  - 基础往前打（专班+清单+销号）
  - 担当往前压（扛事+闭环）
- **第三段（表态收尾）**：对上"请 XX 放心"+"指标不退、目标不减、干劲不松" + 对下"不当旁观者、不做传声筒" + 收尾致谢

### Step 5：金句清单（已嵌入加粗）
1. "时间过半、任务过半，但发展不能过半。"
2. "指标不退、目标不减、干劲不松。"
3. "把节奏往前赶、把基础往前打、把担当往前压。"
4. "不当旁观者、不做传声筒，主动靠前、具体负责、闭环推进。"
5. "周调度、月通报、季评估。"
6. "专班+清单+销号。"
7. "把每一项任务、每一个指标、每一份责任都压实到人头、压实到节点、压实到结果。"

### Step 6：收尾收束
- "请 XX 放心"
- "以更实的作风、更硬的举措、更拼的状态"
- 再次致谢

## 三、最终发言稿

> 注：本稿素材为**模拟场景**（X 占位符为待用户填实的真实数据）。

---

**在全区年中工作推进会上的表态发言**

尊敬的 X 主任、X 副主任，各位领导、各位同仁：

根据会议安排，我代表 X 公司作个表态发言。

**时间过半、任务过半，但发展不能过半。** 今年以来，在 X 委 X 政府坚强领导下，X 公司围绕 X 主线、X 主业、X 主攻方向，X 个重点项目按期推进，X 项关键指标实现时间过半、任务过半。在此，我代表 X 团队，向上级领导和各兄弟单位表示衷心感谢。

下半年的工作，我们重点抓好三件事：

**第一，把节奏往前赶。** X 项目、X 平台、X 基金 X 件事，我们建立**"周调度、月通报、季评估"**机制，把滞后的事项一件件拎出来、一项项推到位，确保 X 月 X 日前 X。

**第二，把基础往前打。** X 改革、X 风控、X 合规三件事，我们建立**"专班+清单+销号"**工作法，X 件事 X 个人盯、X 个节点 X 个节点推，确保 X。

**第三，把担当往前压。** **我们不当旁观者、不做传声筒，主动靠前、具体负责、闭环推进**，X 牵头、X 担责、X 闭环，把每一项任务、每一个指标、每一份责任都**压实到人头、压实到节点、压实到结果**。

请 X 放心，我们一定以**"指标不退、目标不减、干劲不松"**的状态，把下半年的工作做实、做细、做出成效。

最后，恳请 X、X 继续给予 X 公司关心指导。我们将以更实的作风、更硬的举措、更拼的状态，交出一份合格的下半年答卷。

谢谢大家！

## 四、跟通号案例的对比

| 维度 | 通号案例 | 年中推进案例 |
|---|---|---|
| **场景** | 对外商务会谈 | 对内工作推进 |
| **结构** | 5 段式（暖场+态度+干货+表态+收尾） | 3 段式（开场+成绩/干货+表态） |
| **时长** | 5 分钟（1280 字） | 3 分钟（750 字） |
| **对上管理** | "请景区长放心，请牛董事长放心" | "请 X 放心" |
| **对下担当** | "不当旁观者、不做传声筒" | 同上（但更"硬"） |
| **对外姿态** | "既尊重央企专业优势，也体现武侯服务" | "恳请 X 继续关心指导"（对平级） |
| **金句数** | 8 句 | 7 句 |
| **风格** | A+C 混搭 | A（偏硬朗） |
| **政治表述占比** | ~20% | ~25% |
| **特殊挑战** | 不抢主宾戏（6% 股权如何有担当） | 不剩成绩（要直面问题） |

→ **hyfy 的跨场景复用**：同一套金句（"不当旁观者""设得快管得住运转好可持续""同题共答"等）可以按场景重新组合，不是一稿多用，而是**核心机制一致、表达口径随场景变化**。

## 六、hyfy 在 3 段式场景下的特殊处理

| 5 段式 | 3 段式 | 调整原因 |
|---|---|---|
| 暖场段 | **融入开场** | 时间短，暖场要更快（10 秒内） |
| 态度段 | **融入开场** | 一句话点态度，不单独成段 |
| 干货段 | **第二段** | 重点，3 段式的核心 |
| 表态段 | **第三段前半** | 收尾"硬"一点 |
| 收尾段 | **第三段后半** | 一句致谢+一句收束 |

→ **3 段式是 5 段式的"压缩版"，不是"另一种稿子"**。金句、抓手、对上管理、对下担当——一个都不能少。

## 七、可复用的 4 句金句

从本案例提炼，可推广至所有"对内推进"场景：

1. **"时间过半、任务过半，但发展不能过半"** —— 年中/季度推进场景的万能开场
2. **"指标不退、目标不减、干劲不松"** —— 承诺表态三连
3. **"把节奏往前赶、把基础往前打、把担当往前压"** —— 三件事万能结构
4. **"压实到人头、压实到节点、压实到结果"** —— 责任落实三压实
