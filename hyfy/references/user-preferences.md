> hyfy 启动时自动加载本文件，应用你历次沉淀的偏好。
> 本文件由 hyfy 在每次对话中根据你的反馈自动维护。

## 一、写作偏好

### ❌ 禁用项

| 偏好 | 触发场景 | 验证案例 |
|---|---|---|
| 不要"大家上午好"作为固定开场 | 全部场合 | 通号案例 v1（你反馈"不要大家上午好"） |
| 不要"时间节点"（X 月 X 日前完成 X）在干货段 | 项目推进、年中推进 | 通号案例 v2（你反馈"建议不写时间节点"） |
| 不要"几点请求"作为表态收尾 | 对外合作会谈 | 通号案例 v2（你反馈"第四点也不写几点请求"） |
| 不要"大家上午好" | 任何开头 | 同上 |
| 不要"撸起袖子加油干""抓铁有痕踏石留印" | 全部场合 | golden-lines 禁用句清单已收录 |

### ✅ 必用项

| 偏好 | 触发场景 | 验证案例 |
|---|---|---|
| 政治表述克制（不超过 20-30%） | 商务会谈/项目推进/对内推进 | 通号案例验证（~20%）、年中推进案例验证（~25%） |
| 喜欢"X% 承载 100% 属地责任"小比例大担当句式 | 6% 等少数股权场景 | 通号案例金句 |
| 喜欢"合伙人/连接器/合伙人"三角色排比 | 地方国企定位 | 通号案例金句 |
| 喜欢"不当旁观者、不做传声筒"担当表态句式 | 几乎全部表态场景 | 通号 + 年中推进双案例金句 |
| 喜欢"设得快、管得住、运转好、可持续"四字金句 | 合资公司/项目落地 | 通号案例金句 |
| 喜欢"同题共答、同向发力"央地合作收尾 | 央地/政企合作 | 通号案例收尾 |
| 喜欢"压实到人头、压实到节点、压实到结果"三压实 | 责任落实场景 | 年中推进案例金句 |
| 喜欢"指标不退、目标不减、干劲不松"承诺三连 | 推进会表态 | 年中推进案例金句 |
| 喜欢"以今天 X 为新起点"作为收尾开场 | 几乎全部收尾 | 通号 + 年中推进双案例收尾 |

## 五、新增偏好的方式

用 hyfy 写完稿后，告诉 hyfy：

```
"以后 X 场景，要/不要 Y"
"我喜欢 Z 句式"
"以后默认 A+B 风格"
```

hyfy 会自动把偏好沉淀到本文件，下次触发 hyfy 时自动应用。

---

## 六、偏好的"反悔机制"

如果你想**撤销某条偏好**，告诉 hyfy：

```
"取消 X 偏好"
"恢复默认 X 句式"
```

hyfy 会把对应条目移到 `## 七、已撤销的偏好（历史归档）` 章节，保留记录但不应用。
