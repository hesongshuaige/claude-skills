## 六、横向博弈（跨部门+对外）

### 场景A：让别人配合你

**底层逻辑：** 跨部门协作本质是人情债流转——你先帮过 = 他欠你的 = 他更愿意配合。

**三步法：**
1. 先做人情（或引出已有的人情债）："上次XX事我帮你们协调过了"
2. 包装双赢："这对你的考核也有帮助"
3. 降低对方成本："你只需要提供XX，其他的我来做"

**✅❌ 对照：**

❌ "财务部能不能配合一下招商的工作？"
✅ "马丽，这个月入库涉及三笔招商数据需要从财务口径交叉核对。我想了一下，你这边的数据如果直接给到我，我来做交叉比对和出报表，你不用多花时间。这对你年底的财务部绩效分也有支撑——你们的配合度是能体现在招商通报里的。"

❌ "这个事你得帮我处理一下。"
✅ "上次大数据审计的事你帮了大忙，这个缺口一直记着。今天有个事想先请你看一眼——不涉及额外工作量，就是需要你用你的权限点一下审批。如果不行的话我们想别的办法，不勉强。"

**边界条件——当你们之间没有人情债时怎么办：**
- 先主动做人情：在对方还没开口之前帮他一个小忙
- 如果来不及做人情，把合作包装成"上级意图"：在国企，"这是XX会上定的"比"我需要你帮忙"有效得多
- 如果上级意图也没用，就认——这个项目你推不动，找领导协调

### 场景B：厘清边界（高情商版甩锅）

**底层逻辑：** 不是推卸责任，是厘清边界。在混合性关系中，厘清边界必须通过制度/程序来执行，不能通过个人表态。

**✅❌ 对照：**

❌ "这个不归我管。"
✅ "这个事涉及的资金往来性质确实属于财务部的职责范围。我会在工作日志里把这件事标注为【财务部主责+综合部配合】，然后跟马丽那边同步一下。不是推，是程序上这样走对大家都安全——审计下来的时候，职责边界清晰是最重要的保障。"

❌ "你怎么不去找XX部门？"
✅ "根据上次专项推进会定的分工，这块是投资部主责、综合部配合。您先跟黄超那边碰一下，如果需要综合部出材料或者做后勤保障，我这边随时到位。"

**失败模式——厘清边界翻车的三种情况：**
- 对方不接受：说"你别跟我讲程序" → 不要硬刚，说"要不咱们一起找领导碰一下分工？"把边界问题升级为领导决策
- 你厘清边界但之前在这个边界上模糊操作过 → 对方会说"你上次不是这么说的"。这时候必须认——"上次确实边界没划清楚，我们这次把它划清楚"
- 厘清边界同时你还要求对方配合另一件事 → 顺序反了，先厘清，过一段时间再提配合

## 七、完整决策树（带诊断钩子 v2.0）

```
第一步：诊断关系类型
├── Q: 你们之间有过互惠行为吗？
│   ├── 没有 → 工具性关系 → 公平法则：算清楚，不亏不欠
│   ├── 有但不多 → 混合性关系 → 进入第二步
│   └── 多到算不清 → 情感性关系 → 需求法则：全力帮

第二步：诊断面子风险
├── Q: 这件事涉及谁的什么面子？（用诊断工具箱2.1）
│   ├── 涉及道德面子 → 最高警戒！先澄清道德面子，暂停其他操作
│   ├── 涉及能力面子（对方） → 用"情况变化"代替"判断失误"
│   ├── 涉及能力面子（我） → 用事实回应，不辩护
│   └── 涉及社交面子 → 公开给足，私下再说
│
├── Q: 在场的人里谁的面子需要被维护？（用诊断工具箱2.1 Q2）
│   ├── 有上级在场 → 对方的面子需求翻倍
│   ├── 有下属在场 → 对方的面子需求翻三倍
│   └── 只有两个人 → 可以放松但保护道德面子

第三步：匹配策略方向
├── 对上（上级/领导）→ 场景A汇报坏消息 / B争取资源 / C表现思路 / D婉拒任务
├── 对下（下属/团队）→ 场景A BIC批评 / B拒绝诉求 / C绩效面谈 / D推进工作
└── 横向（平级/跨部门）→ 场景A跨部门配合 / B厘清边界

第四步：出话术（四步公式）
→ 先给面子 → 亮事实 → 给台阶/出口 → 留长期钩子

第五步：三问自检
→ 面子：对方听完会丢脸吗？（是→重写）
→ 关系：会把关系推向工具性吗？（是→加人情润滑）
→ 出口：对方知道下一步做什么吗？（不知道→补充）
```
