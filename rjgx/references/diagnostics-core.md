
**万能开头（卡位用）：**

## 二、诊断工具箱（v2.0 新增——从75分到90分的核心）

### 2.1 面子风险诊断（5问）

遇到任何场景，先过这5个问题，确定面子风险的类型和程度：

**Q1：这件事涉及谁的什么面子？**
- 我的道德面子（我被质疑人品/廉洁）→ 最高警戒，优先澄清
- 我的能力面子（我被质疑判断力）→ 用事实回应，不辩护
- 对方的能力面子（我要指出对方的问题）→ 必须保护
- 对方的社交面子（公开场合、上级在场）→ 公开给足
- 三方面子同时涉及 → 分步处理，一次只动一条线

**Q2：在场的人里，谁的面子需要被维护？**
- 只有两个人 → 可以放松，但仍要保护道德面子
- 有第三方在场 → 必须给足社交面子
- 有上级在场 → 对方的面子需求翻倍
- 有下属在场 → 对方的面子需求翻三倍

**Q3：对方最近一次公开被否定是什么时候？**
- 最近一周内 → 对方的面子储备已耗尽，本次必须给面子
- 一个月以上 → 有面子储备，可以适度挑战
- 不记得/不知道 → 默认按"面子储备低"处理，先给面子

**Q4：这件事涉及对方对上级的交代吗？**
- 涉及 → 不仅是你们之间的事，处理不好会连锁反应到对方的上级关系
- 不涉及 → 范围可控，可以更直接
- 不确定 → 按"涉及"处理

**Q5：如果不给面子直接说，最坏结果是什么？**
- 对方记恨但能继续合作 → 审慎操作
- 对方会直接翻脸 → 必须保护面子
- 对方会走组织程序报复（举报/告状）→ 绝对不能碰道德面子

### 2.2 关系类型诊断（3问）

**Q1：你们之间有过互惠行为吗？**
- 有过 → 混合性关系，有人情债在流转
- 还没有 → 工具性关系，先做人情创造债
- 多到算不清 → 接近情感性关系，用需求法则

**Q2：对方有没有因为"人情"帮你做过不在他职责范围内的事？**
- 做过 → 他对你有人情投资，关系偏暖
- 没做过 → 还在工具性层面，需要先做人情
- 你帮过他但他没还 → 他欠你人情债，现在是回收窗口

**Q3：你们的关系会因为这件事往哪个方向走？**
- 加固混合性 → 理想方向
- 滑向工具性 → 需要用人情润滑拉回来
- 推向情感性 → 不必要，保持混合性最安全（可进可退）

### 2.3 权力动态诊断（3问）

**Q1：谁更不可替代？**
- 对方更不可替代 → 你更需要维护对方的面子
- 你更不可替代 → 你有操作空间，但仍不能碰道德面子
- 相互不可替代 → 标准的混合性博弈

**Q2：对方有没有能力让你在其他地方难受？**
- 有能力且有意愿 → 必须柔和
- 有能力但没有意愿 → 可以更直接但留出口
- 没有能力 → 可以不卑不亢

**Q3：这次的结果对谁影响更大？**
- 对你影响更大 → 你更需要对方配合，策略要柔
- 对对方影响更大 → 你有筹码，可以直接但不出恶声
- 互有影响 → 标准的混合性博弈

## 三、核心理论（精简版，保留骨架）

### 3.1 三类人际关系（黄光国）

🥇 **情感性关系** — 需求法则：不分彼此，全力满足。家人、铁杆。国企极少，最多一两个跟自己多年的副手。
🥈 **工具性关系** — 公平法则：算清楚，不亏不欠。纯交易，一次性博弈。多数外部企业、陌生伙伴。
🥉 **混合性关系** — 人情法则：给面子+做人情+等回报。有感情但不深，有工具但不是纯交易。**上级、下级、同事、绝大多数国企内部关系。**

国企80%以上的人际关系是混合性关系。这意味着不能用"铁哥们"的方式（情感性），也不能用"纯交易"的方式（工具性），必须用人情法则操作。

### 3.2 面子三条线

🥇 **道德面子**（人格层面）— 被质疑廉洁、人品。最严重，等于撕破脸。**绝对不能碰。**
🥈 **能力面子**（专业层面）— 被质疑判断力、业务能力。领导尤其敏感。**私下可以挑战，但要用"信息不充分""情况变化"包装。**
🥉 **社交面子**（等级层面）— 公开场合被否定、下级不给上级面子。**公开给足，私下再说。**

面子操作铁律：
- 公开场合只给面子不伤人
- 私下可以挑战能力面子但不能质疑对方能力本身
- 道德面子——连暗示都不要有

### 3.3 人情债四步操作

1. 做人情：你主动给对方资源/帮助/面子 → "这个项目我先推给你看看"
2. 人情债：对方接收后产生亏欠感 → 不要马上索取，等感情发酵
3. 等时机：在对方亏欠感最强时提诉求 → "上次那个事..."
4. 收人情：对方还人情 → 诉求不能超过人情额度，否则关系破裂

国企所有"帮忙""协调""通融"本质上都是人情债的发行和回收。
