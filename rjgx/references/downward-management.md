## 五、向下管理（深度扩展版）

### 场景A：批评下属不伤关系

**底层逻辑：** 批评 = 挑战对方的能力面子。如果同时保护道德面子和社交面子，批评可以接受。

**诊断触发条件：** 下属做了/没做某件事 + 你希望他改进 + 你还要跟他长期共事。

**BIC反馈法（国企版），五步操作：**
1. 打开安全氛围："XX，先坐。这个事我要跟你说一下，但不是否定你这个人"
2. Behavior（行为，对事不对人）：说具体行为，不说性格标签
3. Impact（影响）：让对方看到这件事的连锁后果
4. Consequence（你的态度）：把批评变成"为你好"——这对你的下一步发展有影响
5. Close（关闭+出口）：你能做到吗？→ 能做到就翻篇 + 明确下一步

**✅❌ 对照：**

❌ "你这个方案写得不行，格式都不对。"
✅ "XX，方案的内容方向我是认可的。但格式上有几处没对齐，包括字体、段间距和落款格式。这不是大问题，但董事长看文件很在意这些。下次发之前咱们内部先过一遍格式，行不行？"

❌ "你做事太粗心了。"
✅ "上周那个方案，你交的时候有三个数据没核对——XX数据、YY数据和ZZ的汇总数。导致马总在副总会上拿不出数来，很被动。我知道你不是故意的，但这个习惯如果一直不改，对你下一步的晋升会有影响。这样，从下个方案开始，交之前你自己用这个核对清单过一遍。能不能做到？"

❌ "你怎么又不跟部门长沟通？"
✅ "上次绩效考核通知的事，我说的是'和部门长沟通好就可以发'。但我后来发现通知没发，部门长也没沟通。这件事本身不大，但问题是——你承诺了要做的，中间没有任何反馈。这不是能力问题，是习惯问题。以后接到任务，卡住了第一时间跟我说。这个要求你能不能做到？"

**BIC的五个禁忌：**
- 不要在公开场合用BIC → BIC只在私下有效，公开场合变成羞辱
- 不要用"你总是""你从来不" → 这是攻击人，不是攻击行为
- 不要在对方情绪激动时用 → 先等他冷静，再谈
- 不要跳过Impact直接说Consequence → 对方会觉得你在威胁他
- 不要在同一次谈话里批评超过两件事 → 超过两件，对方防御心态拉满

**边界条件——什么时候BIC不够用：**
- 同一件事批评过三次以上 → BIC失效，需要升级为绩效面谈（场景C）
- 事情涉及其他部门的评价 → 需要加一句"这不是我一个人的判断"
- 下属是你的"老人"（跟你多年）→ 可以用更直接的表达，但仍要保护道德面子

### 场景B：拒绝下属的诉求

**底层逻辑：** 直接拒绝 = 人情债清零，关系变工具性。要让人情流转起来。

**诊断触发条件：** 下属求你办事（升职/加薪/调岗/给资源）+ 你办不到或不想办 + 你还要他继续干活。

**三步法：**
1. 认可诉求的合理性（给面子，保护他的能力面子）
2. 说明客观限制（不是我不帮，是条件不允许——推给制度/时间/程序）
3. 给替代路径（这条路不通，那条可以试试——留出口 + 做人情）

**✅❌ 对照：**

❌ "这个季度提不了职级，等明年吧。"
✅ "提职级这个事，你的业务成绩我是认可的，也到了该提的时候。但咱们公司职级调整是一年一次，上个月的窗口已经关了。这样，我先把你这次的业务成绩单独写进年底的绩效档案，等于提前锁定明年窗口的第一优先级。你可以把它当成一个保底的承诺。"

❌ "这个项目不能给你做，你经验不够。"
✅ "你主动请缨这个态度我很认可。这个项目涉及的XX环节确实比较复杂，之前做过的人踩了不少坑。这样，我让XX带着你先把前面的调研和方案框架跑一遍，你把这一段的经验攒足，下个项目你独立带。不是不给你机会，是帮你把第一步踩稳。"

**边界条件——什么时候不能太柔和：**
- 对方的诉求根本不现实（如刚入职就要副职待遇）→ 可以说"不"但要说明标准是什么
- 你已经用这个方式拒绝过他两次以上 → 第三次必须说清楚"短期内没有可能"
- 对方在试探你的底线 → 可以柔和但不能松口，出口不能太大

### 场景C：绩效面谈/职级调整

**底层逻辑：** 混合性关系中的绩效考核不能像工具性关系那样只算KPI——必须有人情润滑。对方不是数据点，是跟你每天见面的人。

**诊断触发条件：** 季度/年度绩效面谈 + 涉及扣分/降级/排名靠后。

**五步操作框架：**
1. 先肯定人（保护道德+社交面子）："你这个人工作态度没问题"——这句话不能省
2. 再说规则（把结果归因于制度）："按照咱们的考核规则，这一项权重是XX"
3. 用数据讲差距（客观化）："咱们看这个季度的数据"——用数字，不用形容词
4. 给出口（核心）：降级也要给希望——"这次是规则导致的调整，不是对你的否定。下一步从这几个方向发力，完全有机会回来"
5. 留人情（关键）："有合适的项目我优先让你上"——把批评变成投资

**情绪应对预案：**
- 对方沉默 → 主动问"你觉得呢？有什么想说的？"
- 对方辩解 → 不争论，说"我们看数据"，然后回到数据
- 对方委屈/流泪 → 暂停，说"今天我们先把情况碰完，你回去消化一下，明天我们再聊"
- 对方攻击（"你也不公平"）→ 不防御，说"你可以觉得不公平，但这次的评分标准对所有人都是一样的，这是原始数据"

**边界条件——什么时候这个框架不够用：**
- 涉及末位淘汰/辞退 → 不能只做绩效面谈，要有人力资源在场+正式记录
- 对方是中层干部 → 需要额外加一个环节：讨论他作为管理者的表现（不只是个人KPI）
- 你本人也不同意这个绩效结果（是上级压下来的）→ 不要替上级背锅，说"这是公司的整体评估"

### 场景D：推进工作——用绩效做管理工具

**底层逻辑：** 绩效考核不是惩罚工具，是缩短"问题被发现→被解决"的滞后时间。扣分不是目的，让被扣的人知道下一步做什么能往回补才是目的。

**操作铁律：**
- 公开表扬、私下批评——保护社交面子
- 扣分必须附带"下一步做什么能补回来"的具体路径
- 通报中的正负面比例：7:3（七分表扬三分鞭策）

**✅❌ 对照：**

❌ "XX部门上个月考核垫底。"
✅ "XX部门上个月有三项指标没达标，主要是招商入库率、材料时效和跨部门配合度。但他们在项目尽调质量上是满分的。下一步重点抓入库率和时效这两项，下个月我们再看。有需要协调的直接找我。"

**失败模式——什么时候通报会起反作用：**
- 只通报不跟进 → 下属会觉得通报就是走过场
- 负面比例过高 → 变成"批斗"，团队士气崩盘
- 同一个人的同一个问题连续三期没改善 → 不是管理工具的问题，是人岗匹配的问题，需要启动人员调整
