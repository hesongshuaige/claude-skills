## 工具选择决策树

```
老板说"我想用AI做XXX"
    │
    ├─ 有没有现成的工具能做？
    │   ├─ 有 → 直接用现成工具（优先）
    │   └─ 没有 → 继续往下看
    │
    ├─ 团队有没有人会写提示词？
    │   ├─ 有 → 用AI助手/智能助手API自建
    │   └─ 没有 → 用Coze/扣子（可视化搭建）
    │
    └─ 预算多少？
        ├─ <500/月 → Kimi/智能助手免费版 + Excel
        ├─ 500-2000/月 → 订阅1-2个专业工具
        └─ >2000/月 → 可考虑定制开发
```
