# Synthesis Rubric

The output must be a learning system, not a translation bundle.

## Anti-Translation Rules

Do not:

- Translate README sections mechanically.
- Dump source lists without interpretation.
- Treat stars as quality.
- Mix facts and opinions without labels.
- Publish tool names without explaining when to use them.

Do:

- Extract the underlying method.
- Compare competing approaches.
- Identify failure modes.
- Convert examples into reusable templates.
- Produce training tasks and landing plans.

## Synthesis Layers

Every substantial topic should include:

1. **Mental model**: what the topic is and what problem it solves.
2. **Expert workflows**: how skilled users apply it.
3. **Tool ecosystem**: notable repos/tools and selection guidance.
4. **Case/anti-case**: examples and failure modes.
5. **Templates**: prompts, configs, checklists, SOPs.
6. **Training system**: exercises, scoring, progression.
7. **Landing plan**: first actions for the user's context.

## Gap Analysis

When updating an existing knowledge base, compare new evidence against current pages:

- Missing concepts.
- Missing workflows.
- Missing examples.
- Missing anti-patterns.
- Missing automation/maintenance.
- Stale source list.
- Overly general advice that needs user-context adaptation.
