# Feishu Knowledge Base Structure

Use a predictable structure so future updates can add pages without breaking the learning path.

## Standard Structure

```text
00｜首页与学习路径
01｜核心概念
02｜高手工作流
03｜工具生态与资料源
04｜案例与反例
05｜模板与检查清单
06｜训练计划
07｜落地场景与评分表
08｜更新记录
```

## Publishing Rules

- Keep the index page authoritative even if sidebar ordering differs.
- Use clear numbered page titles.
- Add source links in a dedicated source page.
- Verify page count after publishing.
- Fetch the index after updating it.
- Avoid deleting pages unless explicitly requested.

## Update Modes

- **Create**: new topic or user asks for new knowledge base.
- **Append**: add pages to an existing knowledge base.
- **Refresh**: update source list, stale sections, index, and update log.
- **Deepen**: add cases, anti-patterns, training tasks, and scoring.
