# Quality Checklist

Run this before claiming completion.

## Research Quality

- At least one authoritative/official source was checked when available.
- High-rated GitHub sources were ranked by more than stars.
- Search date is recorded for current topics.
- Sources are linked.
- Weak or stale sources are not over-weighted.

## Synthesis Quality

- Content is not a translation dump.
- Facts, inference, and recommendations are distinguishable.
- The output contains expert workflows.
- The output contains anti-patterns or failure modes.
- The output contains templates/checklists.
- The output contains training or landing actions.

## Feishu Quality

- Index page exists and has reading order.
- Source/evidence page exists or was updated.
- Page count was verified.
- Important updated pages were fetched or otherwise checked.
- Sidebar ordering issues, if any, are disclosed.

## Update Quality

- Existing content was preserved unless replacement was intentional.
- New material fills an identified gap.
- Source page or update log includes what changed.
- Next suggested mining direction is stated.
