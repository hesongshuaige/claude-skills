# Evidence Ledger

Maintain a compact evidence ledger for each mining run. Include it in the final report or source page when useful.

## Ledger Format

| Source | Type | Score | Used For | Notes |
|---|---|---:|---|---|
| owner/repo or URL | official / repo / awesome / article / issue | 0-40 | concept / workflow / tool / risk / example | why selected |

## Required Fields

- Search date.
- Topic and angle.
- Inclusion criteria.
- Exclusion criteria.
- Top sources used.
- Sources rejected and why, when rejection is non-obvious.
- Facts vs inferences.

## Evidence Labels

Use these labels in synthesis:

- **Sourced fact**: directly supported by source.
- **Community pattern**: appears across multiple independent sources.
- **Inference**: reasoned conclusion from evidence.
- **Recommendation**: suggested user action.
- **Open question**: unresolved, needs user context or further research.

## Freshness Rules

- Include exact search date for current topics.
- Re-check official docs and GitHub repos when the user asks for "latest", "current", or "now".
- Flag potentially stale pages or repos.
