## 逐字稿任务表

| 字段 | 内容 |
|---|---|
| 原文证据 | 原句或时间点 |
| 任务 | 动作 + 交付物 |
| 负责人 | 已确认的人；不确定写待确认 |
| 截止时间 | 原文日期；不完整写待确认 |
| 依赖 | 前置条件、协作人、资料 |
| 优先级 | 原文明确值或待确认 |
| 疑点 | 错别字、同音词、歧义 |
| 审核结果 | 用户确认、修改、保留疑点 |
