# Source Type Rules

Use these rules to adapt analysis to the source.

## 逐字稿

- Remove filler words, repeated phrases, and obvious transcription artifacts.
- Preserve speaker intent and sequence.
- Prefer extracting the main argument, repeated emphasis, and any operational steps.
- Do not turn casual remarks into polished claims unless the source clearly supports them.

## 录音稿

- Treat timestamps, pauses, and broken sentences as noise unless they clarify context.
- Merge duplicated points across the recording.
- Mark unclear or inaudible segments as `原文不清晰` instead of guessing.

## 网页文章

- Preserve title, author, platform, URL, and publication time when available.
- Distinguish the author's argument from quoted third-party information.
- Extract concrete examples, data, and methods before stylistic commentary.

## 社媒帖子

- Expect compressed, opinionated, or emotional expression.
- Be stricter about low-density claims and anxiety marketing.
- Prefer `可二创` or `仅存档`; use `长期参考` only when the post contains a durable framework or evidence.

## 报告资料

- Prioritize definitions, data, conclusions, methodology, and limitations.
- Keep numbers and units exact.
- Do not simplify away caveats that affect interpretation.

## 访谈对话

- Separate each speaker's claims when speaker identity matters.
- Extract disagreements, examples, and tacit assumptions.
- Do not attribute one speaker's view to another.

## 飞书文档

- Preserve document title, wiki/doc URL, owner or author if available.
- When updating Feishu, keep the generated card separate from the source document unless the user asks to edit the original.

## 本地文件

- Record the file name and path as source information when no external source exists.
- If the file is a draft or notes fragment, avoid overstating authority.
