## 场景1：用户首次使用（飞书文档）

**用户输入**：
```
用aisc处理这个：https://aiawaken.feishu.cn/wiki/RHmSwYRYciJOsXkXvG0ckPQwnF8
```

**Agent 自动执行**：

```
1. 获取文章内容
   → 飞书知识库链接，自动识别
   → 获取文档：《一人公司 AI Agent 文件管理实操手册》
   
2. 全9栏分析（自动执行）
   → ## 1. 开篇hook：AI越用越乱的3个症状...
   → ## 2. 30秒看懂：周知是AI超级个体创业者...
   → ## 3. 文章质量：优质...
   → ## 4. 逻辑骨架：4个核心论点...
   → ## 5. 可实操动作：6个动作 + 3个Prompt...
   → ## 6. 没讲透的坑：4个坑...
   → ## 7. 边界判断：适合3类人，不适合2类...
   → ## 8. 举一反三：5个迁移场景...
   → ## 9. 核心一句话：AI越用越乱...

3. 创建知识库
   → "学习卡片沉淀库" 不存在
   → 创建成功，space_id: 7646065151728192711
   
4. 创建索引页面
   → 创建"学习卡片沉淀库索引"

5. 上传卡片
   → 标题：【卡片】一人公司AI Agent文件管理实操手册
   → 创建成功

6. 更新索引
   → 添加一行：| 2026-05-31 | 【卡片】一人公司AI Agent... | AI效率 | AI越用越乱... |
```

**返回给用户**：

## 场景3：内容获取失败

**用户输入**：
```
用aisc处理：https://需要登录的网站.com/article
```

**Agent 执行**：

```
1. 获取文章内容
   → curl 抓取失败（SPA/需要登录）
   → 无法获取内容
```

**返回给用户**：
```
⚠️ 无法自动获取该页面内容（可能需要登录）

请选择：
1. 直接粘贴文章内容给我
2. 提供其他可访问的链接
3. 告诉我文章主题，我帮你总结
```
