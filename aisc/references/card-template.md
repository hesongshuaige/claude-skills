# Card Template

Use this template for the final AISC card. Keep headings unchanged.

```markdown
# AISC 学习卡片

## 来源信息
- 标题：未提供
- 作者 / 发布者：未提供
- 来源 / 平台：未提供
- 链接：未提供
- 发布时间：未提供
- 来源类型：逐字稿 / 录音稿 / 网页文章 / 社媒帖子 / 报告资料 / 访谈对话 / 飞书文档 / 本地文件 / 其他
- 获取时间：YYYY-MM-DD

## 摘要
第一句话。
第二句话。
第三句话。

## 关键词
关键词1、关键词2、关键词3、关键词4、关键词5

## 内容分类
教程方法论 / 行业观察 / 个人经验 / 案例拆解 / 观点输出 / 知识科普 / 资料整理 / 情绪表达

## 核心观点
1. 不超过三条，每条必须能从原文找到依据。
2. ...

## 关键知识点
1. 具体知识点。
2. 具体知识点。
3. 具体知识点。

## 金句 / 原文摘录
无

## 学习卡片增强

### 30秒看懂
用一小段话说明这个材料最值得带走的东西。

### 逻辑骨架
问题：...
方法：...
结果：...

### 可实操动作
1. 动作：为什么这么做；做完会看到什么；做之前要准备什么。

### 没讲透的坑
1. 原文提到但没有讲清楚的地方；如果没有，写“无”。

### 边界判断
适合：...
不适合：...
自测问题：...

### 举一反三
可迁移场景：...
迁移前自检：...

### 核心一句话
20字左右，保留原意，不强行押韵。

## 可复用价值
说明这份资料适合在哪些具体场景复用，以及为什么。

## 价值判断与入库建议
长期参考 / 可二创 / 仅存档 / 不建议入库。原因：...
```

## Light Card

When the quality gate chooses `仅存档` or the material lacks enough density, omit `学习卡片增强` and keep the card concise.
