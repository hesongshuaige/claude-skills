# 金句库：A + C 双风格

> fy 风格的灵魂是"金句"。本库按**功能维度**（开场/态度/工作方法/对上/对下/对外/收尾）分类，每条提供 A 风格、C 风格、A+C 混搭 三个版本。

## 风格速查

| 风格 | 配比 | 关键词 | 适合谁 |
|---|---|---|---|
| **A 主流混合** | 70% 市场 + 30% 政治 | 合伙人/连接器/闭环/靠前/扛事 + 高位推动/同题共答 | 国企/央企对接（**默认**） |
| **C 高度市场** | 90% 市场 + 10% 政治 | 赋能/共建/共赢/生态/链接 | 民营/外资/产业论坛 |
| **A+C 混搭** | 主体 A，关键金句 C | 主体市场，关键处点政治 | 既要专业又要政治正确（**最常用**） |

## 一、开场金句

### A 风格
- "非常荣幸，在 XX 区长/董事长的亲自推动下，我们与 XX 一行相聚 X、共谋 X。"
- "这是一个 X 深化央地合作、布局战略性新兴产业的标志性时刻。"
- "今天 X，不仅是一场业务对接，更是一场双向奔赴。"

### C 风格
- "很高兴与各位新老朋友相聚 X、共话 X。"
- "X 是一个让产业人愿意扎根的地方。"

### A+C 混搭
- "非常荣幸，在 XX 区长的亲自推动下，我们与 XX 集团 XX 董事长一行相聚武侯、共谋合作。这是武侯深化央地合作、布局战略性新兴产业的标志性时刻。"

### 反例（禁用）
- ❌ "在 XXX 的坚强领导下，在 XXX 的亲切关怀下……"
- ❌ "金风送爽、丹桂飘香，在这美好的季节……"
- ❌ "为深入贯彻 XXX 精神……"

## 二、态度金句

### A 风格
- "X% 虽然比例不大，但分量很重——这 X% 承载的是 X 区的产业意志、属地责任和国企担当。"
- "坚决按 X 委 X 政府部署，把 X 作为当前重点任务来抓。"
- "既积极推进，也专业推进；既服务合作大局，也守住国资合规底线。"

### C 风格
- "我们不缺席、不被动，主动参与、深度绑定。"
- "这件事不是一道选择题，是一道必答题。"

### A+C 混搭
- "合资公司 6% 股权，比例不大，但分量很重——这 6% 承载的是武侯区的产业意志、属地责任和国企担当。"

### 反例（禁用）
- ❌ "充分认识 X 的极端重要性"
- ❌ "切实增强 X 的责任感使命感紧迫感"
- ❌ "以高度的政治自觉、思想自觉、行动自觉……"

## 三、工作方法金句

### A 风格
- "设得快、管得住、运转好、可持续。"
- "把基础打扎实、把节奏抓起来、把资源聚起来。"
- "三个一：一个总部、一个主体、一支团队。"
- "专班推进、专业管控、服务落地。"

### C 风格
- "小步快跑、快速迭代。"
- "先把 X 跑通，再复制拓展。"
- "今天先把地基打牢，明天才能起高楼。"

### A+C 混搭
- "设得快、管得住、运转好、可持续。"
- "把节奏抓起来、把基础打扎实、把资源聚起来。"

### 反例（禁用）
- ❌ "切实抓好、抓出成效、抓出亮点"
- ❌ "挂图作战、挂账销号"
- ❌ "高位推动、高位协调"

## 四、对上管理金句

### A 风格
- "请 XX 放心，我们 X。"
- "坚决服从服务全区 X 大局。"
- "既会把事情往前推，也会把规则把握好。"

### C 风格
- "请 XX 见证，我们一定 X。"
- "我们会用结果说话。"

### A+C 混搭
- "请 XX 区长放心，请 XX 董事长放心。我们坚决服从服务全区开放合作大局，既会 X，也会 X。"

### 反例（禁用）
- ❌ "在 XX 的正确领导下，我们一定能够……"
- ❌ "不辜负 XX 的期望和重托"
- ❌ "为 XX 增光添彩"

## 五、对下担当金句

### A 风格
- "不当旁观者、不做传声筒，主动靠前、具体负责、闭环推进。"
- "我们愿意做央企落地的'第一站'、区企协同的'连接器'、产业培育的'合伙人'。"
- "X 牵头，专人、专责、专办。"

### C 风格
- "这件事，我们不甩手、不旁观、不掉链子。"
- "我们做这件事的 X，不是 X，是 X。"

### A+C 混搭
- "我们不当旁观者、不做传声筒，而是主动靠前、具体负责、闭环推进。"

### 反例（禁用）
- ❌ "切实把 X 责任扛在肩上、抓在手上、落实在行动上"
- ❌ "以钉钉子精神抓好 X"

## 六、对外姿态金句

### A 风格
- "既尊重 X 等合作方的专业优势，也把 X 的服务效率、营商环境和国企担当体现出来。"
- "我们把合作从'项目合作'做成'产业合作'，从'一家公司'做成'一个生态'。"
- "真诚希望 X 把更多 X 导入 X，把 X 作为 X 的重要支点。"

### C 风格
- "我们不是简单的甲方乙方，是共创共建的合伙人。"
- "今天我们做的不只是一单生意，是一片生态。"

### A+C 混搭
- "既会尊重央企、城投等合作方的专业优势，也会把武侯的服务效率、营商环境和国企担当体现出来。"

### 反例（禁用）
- ❌ "实现 X 互利共赢、共同发展"
- ❌ "携手共创美好未来"
- ❌ "强强联合、优势互补"

## 七、收尾金句

### A 风格
- "以今天 X 为新起点，在 X 关心指导下，在 X 大力支持下，各方同题共答、同向发力。"
- "努力把 X 打造成为央地合作、区企协同、产业落地的示范项目。"
- "为 X 建设贡献央地国企的联合力量。"

### C 风格
- "我们一起，把这件事做成。"
- "让 X 这片 X 的土地，生长出 X 的产业。"

### A+C 混搭
- "真诚期待以今天会见为新的起点，在 XX 区长的关心指导下，在 XX 董事长和 XX 集团的大力支持下，各方同题共答、同向发力，尽快推动合资公司落地见效，努力把这个项目打造成为央地合作、区企协同、产业落地的示范项目。"

### 反例（禁用）
- ❌ "让我们携起手来，共同谱写 X 新篇章"
- ❌ "为实现 X 奋斗目标而努力奋斗"
- ❌ "开创 X 更加美好的明天"

## 八、即兴讲话三句式

> 适用场景：没有完整稿子，需要 3-5 分钟即兴讲话。

### 模板
- **第一句（暖场）**："今天 X 这场 X 活动，我有三句话想说。"
- **第二句（态度）**："第一句，关于 X，我想说 X；第二句，关于 X，我想说 X。"
- **第三句（收尾）**："总之，X。让我们一起 X，谢谢大家。"

### 即兴金句
- "我理解、我认同、我承诺。"
- "三个 X：方向明、举措实、保障强。"
- "向 X 学习、向 X 看齐、向 X 努力。"
- "既来之，则安之；既安之，则干之。"

## 九、金句自检 4 问

写完金句后，必须用 4 问自检：

1. **脱离上下文还能引用吗？** —— 不能就不是金句
2. **有具体抓手吗？** —— 全是形容词就是空话
3. **听者能复述给同事吗？** —— 复述不出就是无效
4. **会让人觉得"这才是我想说但没说出来的"吗？** —— 没感觉就是没到位

## 十、禁用句清单（高优先级黑名单）

> 这些句式一旦出现，听者立刻识别为"套话"或"AI 写的"。

- "在 XXX 的坚强领导下"
- "以 XXX 为契机"
- "谱写 XXX 新篇章"
- "不忘初心、牢记使命"（党建纯场合除外）
- "切实增强 XXX 的责任感使命感"
- "挂图作战、挂账销号"
- "撸起袖子加油干"
- "抓铁有痕、踏石留印"
- "使命光荣、任务艰巨"
- "重要讲话、重要指示、重要批示"
