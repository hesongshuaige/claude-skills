# 结构库：5 段式 / 3 段式 / 即兴式 骨架

> 给 fy 提供"可拆装"的发言稿骨架。所有骨架都必须能嵌入金句（加粗位）。

---

## 一、5 段式骨架（推荐：商务会谈、项目推进表态、调研接待）

适用时长：5-10 分钟（1250-2500 字）

### 结构

```
[第 0 段：主送]
"尊敬的 XX，XX，XX："
└── 顶格不缩进，点出关键听众

[第 1 段：暖场+高情商管理]  ← 30 秒
- 感谢主宾（不抢主宾戏）
- 致敬对方（专业认可 + 行业判断）
- 把今天会谈的意义"定调"

[第 2 段：态度/立场]  ← 1 分钟
- 我方定位（小比例大担当 / 主动靠前 / 闭环推进）
- 政治站位（"按 X 委 X 政府部署"+"当前重点任务"）
- 三条定位（做强支撑/做优服务/做实协同 等）

[第 3 段：核心干货]  ← 2-3 分钟
- 三个方面工作（专班 / 专业 / 服务）
- 或：3 个节点（避免时间表）/ 3 个突破 / 3 个一
- 每一项必须有具体抓手（数字/项目/机制/承诺）

[第 4 段：表态承诺]  ← 1 分钟
- 对上管理："请 XX 放心"+ "既 X，也 Y"
- 对下担当："不当旁观者，不做传声筒"
- 对外姿态："既尊重 X，也体现 X"
- 三个角色排比（"第一站 / 连接器 / 合伙人"）

[第 5 段：收尾]  ← 30 秒
- "以今天 X 为新起点"+"在 X 关心指导下"+"在 X 大力支持下"
- "同题共答、同向发力"
- "央地合作 / 区企协同 / 产业落地的示范项目"
- "为 X 建设贡献央地国企的联合力量"
- 再次致谢
```

### 5 段式排版骨架（与 pb 兼容）

| 段落 | 元素 | 排版 |
|---|---|---|
| 主送 | 尊敬的 XX： | 仿宋 16.5pt 顶格 |
| 暖场 | 1 段正文 | 仿宋 16.5pt 首行缩进 |
| 态度 | 一、XX | 黑体 16.5pt 首行缩进 |
| 干货 | 二、XX（下面接 1./2./3. 三个二级或加粗子段） | 楷体 16.5pt 加粗 |
| 表态 | 三、XX | 黑体 16.5pt 首行缩进 |
| 收尾 | 1 段正文 | 仿宋 16.5pt 首行缩进 |
| 落款 | 单位 + 日期 | 仿宋 16.5pt 右对齐 |

## 二、3 段式骨架（推荐：项目推进、签约/揭牌、接待致辞）

适用时长：3-5 分钟（750-1250 字）

### 结构

```
[第 0 段：主送]

[第 1 段：开场+意义]  ← 30 秒
- 一句话点出场合意义
- 一句话点出合作/项目的战略价值
- 引出金句（"X 是一个标志性时刻"）

[第 2 段：进展+承诺]  ← 2-3 分钟
- 当前做了什么（数据/项目/机制）
- 下一步要做什么（机制+承诺，避免具体时间表）
- 必须有 1-2 个金句（"设得快管得住运转好可持续"等）

[第 3 段：收尾+致谢]  ← 30 秒
- 共同愿景
- 致谢各方
- 一个收尾金句
```

## 三、即兴式骨架（无稿场景）

适用时长：3-5 分钟

### 结构

```
[暖场] 30 秒
"今天 X 这场 X 活动，我有 X 句话想说。"

[三个"我"] 1 分钟/句
- 第一句：关于 X，我理解 X。
- 第二句：关于 X，我想说 X。
- 第三句：关于 X，我承诺 X。

[收尾] 30 秒
"总之，X。让我们一起 X，谢谢大家。"
```

### 即兴讲话适配场景
- 工作餐上的简短致辞
- 仪式上的临时发言
- 调研途中被要求讲两句
- 会议讨论中被点名发言

### 即兴讲话的"备料"（用 fy 提前准备）
- 3 个"我"句式
- 1 个金句
- 1 个数据
- 1 个具体项目/案例

## 四、混合骨架（5 段式 + 3 段式嵌套）

适用场景：工作汇报 + 综合表态（如接待领导调研+汇报+表态）

### 结构

```
[开场] 3 段式开场
[核心 1] 5 段式（专题汇报）
[核心 2] 5 段式（表态承诺）
[收尾] 3 段式收尾
```

混合骨架一般用于 15-30 分钟的综合汇报场合。

## 五、节奏控制

### 时间分配黄金比例

| 段落 | 占总时长 |
|---|---|
| 暖场+主送 | 5-10% |
| 态度/立场 | 15-20% |
| 核心干货 | 50-60% |
| 表态承诺 | 10-15% |
| 收尾 | 5-10% |

### 加粗金句的"重音位"

讲话时的重音位（语速放慢、稍作停顿、加点力度）：

1. **主送段的最后一句**（如"莅临，表示衷心的感谢和热烈的欢迎"）
2. **态度段的"小比例大担当"**（如"6% 虽然比例不大，但分量很重"）
3. **干货段每段的小标题**（如"专班推进，把节奏抓起来"）
4. **表态段的"请 XX 放心"**
5. **表态段的"既 X 也 Y"排比**
6. **收尾段的"同题共答、同向发力"**
7. **收尾段的"示范项目"**

### 节奏检查
- 暖场：慢-中
- 态度：稳
- 干货：稳-快
- 表态：稳-慢
- 收尾：慢

## 六、避坑结构

| 错误结构 | 正确做法 |
|---|---|
| 开头铺陈太久（30 秒+才进入正题） | 主送后 5 秒内进入正文 |
| 全是干货没有态度 | 干货前必须有态度段 |
| 态度段空泛（无具体抓手） | 态度段也要有抓手（如"6% 承载 100% 属地责任"） |
| 表态段不呼应主宾 | 必须"请 XX 放心"+"既 X 也 Y" |
| 收尾段"让我们共同……" | 用"以今天 X 为新起点"或"在 X 关心指导下"结构 |
| 全篇一个节奏，没有重音 | 至少 5 个加粗金句作为重音位 |
