# 合规边界：什么不能写、什么要核实

> fy 在国企/私募/政务/党建场景下的合规红线。违反任一条 = 稿件不合格。

---

## 一、绝对不能编造的内容

| 内容类型 | 红线 | 应对 |
|---|---|---|
| **政策文件** | 不得编造"中央 X 号文件""国务院 X 号令""X 部 X 号文" | 如需引用，标记 `<待用户核实>`，让用户提供 |
| **政策表述** | 不得编造领导人原话、未公开的会议内容 | 仅可引用公开且用户提供的原话 |
| **数据/案例** | 不得编造"据 X 统计""X 年 X 月 X 日 X 报报道" | 数据必须用户素材提供 |
| **文件依据** | 不得编造"根据《X 法》第 X 条" | 同上 |
| **历史事件** | 不得编造"X 领导 X 年 X 月考察 X" | 仅可使用用户素材 |

**自检问**：这段话里有没有我不能确认来源的内容？有 → 标记 `<待核实>` 或删除。

---

## 二、可能涉及合规风险的内容（要主动提示）

### 1. 数字/时间/金额承诺
- ❌ "我们承诺 X 年 X 月前完成 X 亿元投资"
- ❌ "确保 X 年内产值突破 X 亿"
- ✅ 用"目标""争取""力争"等软性词，或标记 `<待用户确认具体数字>`

### 2. 对方企业的描述
- ❌ 编造对方企业未公开的财务数据、未公开的奖项
- ✅ 仅使用用户素材提供的信息

### 3. 政策表述
- ❌ "坚决贯彻 XX 会议精神"（如未明确是哪次会议）
- ✅ 仅在用户提供会议名称/文件标题后引用

### 4. 排名/比较
- ❌ "我们处于全国第一/全球领先"
- ❌ "X 行业我们做得最好"
- ✅ 用"处于第一梯队""具备领先优势"等弱化表述

### 5. 党政职务表述
- ❌ 混淆党委书记、董事长、总经理的职责边界
- ❌ 在不同场合称呼同一人时不一致
- ✅ 让用户提供准确的职务清单

---

## 三、场景特定合规

### 国企场景
- 不得泄露未公开的国资监管数据
- 不得对未公开的产权/股权变更做承诺
- 涉及"国资保值增值"的表述要让用户确认

### 私募基金场景
- 不得对收益做明示或暗示承诺
- 不得对未备案的基金做宣传
- "投资者收益"等表述要让用户确认合规

### 政务场景
- 不得使用未公开的会议内容、未公开的领导讲话
- 涉及"政治站位"的表述要让用户确认方向

### 党建场景
- 政治表述占比可以到 50-60%
- 引用领导人原话必须用户确认或公开来源
- "四个意识""两个维护"等表述要让用户确认是否合规使用

### 对外/外商合作场景
- 不得泄露国家秘密、未公开的产业政策
- 涉及外资准入、数据出境等敏感话题要让法务确认

## 四、政治站位占比硬约束

| 场景 | 政治表述占比上限 |
|---|---|
| 商务会谈/项目推进 | **30%** |
| 接待致辞/签约揭牌 | 20% |
| 工作汇报 | 30% |
| 调研接待 | 30% |
| **党建/政治场合** | **50-60%**（可放宽） |

**自检方法**：把稿子里所有带"政治"色彩的句子圈出来，看占比是否超标。

---

## 五、必须主动提示用户核实的 6 类内容

fy 在以下情况必须主动问"请确认"：

1. **数字/时间/金额**：X 亿、X 月、X% 这类硬数据
2. **政策文件**：X 号文件、X 会议、X 法规
3. **对方企业情况**：财务、奖项、排名、未公开信息
4. **领导职务**：称呼、排序、是否在职
5. **历史事件**：X 年 X 月 X 日发生了什么
6. **敏感表述**："第一""唯一""率先""首位"等排名类用词

## 六、错别字与硬伤检查清单

> fy 输出前必须自检。

- [ ] 主送人员职务准确（"XX 同志""XX 董事长"等）
- [ ] 公司/单位名称准确（不漏字、不写错别字）
- [ ] 数字单位一致（"亿元"全篇一致）
- [ ] 标点全角（，。：；""） vs 半角
- [ ] "的/地/得"用法正确
- [ ] 政策表述准确（不是"供给侧"写成"供结侧"等）
- [ ] 没有错别字（"区域性"不是"区域性"）
- [ ] 主送排序符合规矩（按职务从高到低）

---

## 七、合规失分后如何快速修复

| 失分类型 | 修复方法 |
|---|---|
| 编造了数据 | 删除或标记 `<待核实>` |
| 政治表述过多 | 改用市场化表达（合伙人/连接器/闭环） |
| 引用了领导人原话但用户未确认 | 删除原话，改为转述 |
| 时间节点过于具体 | 改用"目标""争取""力争"等软性词 |
| 排名类用词 | 改用"处于第一梯队""具备领先优势" |
| 编造了对方信息 | 立即删除，等待用户提供 |
