# skillup — 提示词入库流水线（分型分流·结果导向）

> **规则优先级**（冲突时以此为准）：最高铁律 > 硬要求 > 流程。

## ⭐ 最高铁律：先分型，再按型验证（结果导向，不卡绝对分）
所有交付物（提示词/使用场景/举一反三）必须**实测好用**才交付，绝不交付 60 分马马虎虎的东西（用户硬要求，见 memory 索引 verify-before-deliver）。

**"好用"按类型分两档**（详见 REFERENCE §十）：

**A 类·简单类（单轮·输入→输出清晰）= skillup 主力**
- 适用：写作 / 拆解 / 分析 / 设计 / 学习 / 框架类（共 12 种框架）
- 标准：**实跑 2-3 个代表性真实场景，输出有用**（能解决问题、无 AI 腔、无 编造）+ 评审找不出致命硬伤（收敛 = 连续一轮找不出新致命硬伤）= 合格。**不卡评审绝对分**。
- 评审框架（§八）= **找问题工具**（找完致命硬伤即收敛），不是绝对裁判（视角漂移会震荡）。

**B 类·复杂类（多轮·诊断型）= 不适合单条 prompt**
- 适用：评审 / 魔鬼代言人 / 尽调 / 投决（需多轮交互+状态+分支）
- 处理顺序：① 先砍成**单轮简化版**（去硬停止/多轮/C 分支罢工，信息不够就老实说"给方向性判断"+给方向）；② 简化版按 A 类标准验；③ **试 3 版仍跑不通**（成功率<50%）→ 劝退（标注"超出单条 prompt，建议做 agent/工具"，交用户定）。
- 判例：董事会拷问 v5 简化 6 版仍卡壳（层 2/3 实跑 0/11）。

**判型判据**（中间地带看判例 §十）：单轮一次出结果 = A；要来回追问/记状态/分情况 = B。判不准先按 A 试 1 场景探路，跑不通升 B。

## 何时用 / 何时不用
- **用**：把一段提示词做成飞书库文档，或优化库里已有。
- **不用**：只想本地改一段不入库 / B 类砍完简化版仍跑不通（劝退）。
- 改内容/改名默认不断链（overwrite / PATCH new_title）；删旧建新才变链接，动手前告知用户。

## 拿不准就先问
任何犹豫先问用户。兜底（用户答"随便"时显式说默认值让其一键否决）：**入库**（默认入）；类型判不准默认**按 A 类但先跑 1 场景探路**，确认类型再补跑。

## 不可违背的硬要求
1. 举一反三从这些场景池选（REFERENCE §一，共 6 个）：**新媒体运营 + 私募股权 GP/LP + 人事行政 + 财务管理**。禁健身/外教/驾校等无关场景。
2. 所有交付物实测好用才交付（见最高铁律 + §八 + §十）。A 类实跑 2-3 代表性场景；B 类简化或劝退。
3. 上传文档格式 = 背景→原版→优化版→用法→使用场景→设计要点→举一反三（7 段，**不写实测过程/评估表**）。原版+背景必留。
4. 使用场景块按 §九 模板（4 字段：什么情况用 / 典型输入 / 预期输出 / 注意事项）；举一反三每条附**完整可发提示词**。验证后台做，文档只给「场景说明 + 提示词」。

## 流程
1. **提取**：从用户当轮对话/附件/PDF 提取【背景】【原版】【使用场景】。
2. **判型**：单轮=A；多轮=B（判不准先 A 试探）。详见 §十判例。
3. **写优化版**（保留人设+补硬约束，REFERENCE §三）。B 类同时砍单轮简化版。
4. **实测验证**：A 类实跑 2-3 代表性场景（贴合 4 池主业），看输出有没有用；评审框架（§八）找致命硬伤到收敛。
5. **使用场景（3-5，§九模板）+ 举一反三（6，4 池选）**：每个实跑确认有用。
6. **3 场景实跑输出有用 + 评审无致命硬伤 → 上传**：`scripts/upload.sh "【功能】大白话名" <md文件路径>`（upload.sh 只上传+挂库根，**不更索引**）。
7. **更新索引页**（9 类 6 字段，REFERENCE §七）：9 类 = 写作/拆解/分析/开发/驾驭/决策/设计/学习/框架。
8. **交付**：文档链接 + 索引页链接 + **实测摘要**（对话内交付，**不写入飞书**；含：3 场景名 + 每场景输出有用/没用+一句理由 + 劝退标注）。

## 飞书库（配置 env/conf，不硬编码）
- space_id = `$SKILLUP_SPACE_ID`、索引页 file_token = `$SKILLUP_INDEX_TOKEN`（用于 overwrite/fetch）—— 两值从环境变量或 `~/.config/skillup.conf` 读，未配则 upload.sh 报错退出（配置见 README）。
- 新条目 node_token（拼 URL 用）由 upload.sh 运行时输出，**不硬编**；拼链接用 NODE_TOKEN 不是 file_token，否则打不开。
