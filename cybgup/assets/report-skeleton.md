# 初研报告完整骨架

可直接套用的成稿模板。融合最完整的样稿（成长期/成熟期完整型）与打假型样稿结构。占位符 `【】` 处替换为项目实际内容；`（提示：...）`为写作指引，定稿时删除。

报告分两层：前半"基本情况"是**事实陈述**（每个数据标来源、年份、证据级别），后半"初步研判"是**判断论证**（基于事实、有数据与行业对标支撑）。两层不可混写。

证据三级标注（全文统一）：
- 【已查证】= 联网搜索核实过的公开信息，标来源+年份（如"根据公开信息（企查查，2025年），..."）
- 【企业自述】= BP/推介资料/访谈提供的数据（如"根据企业提供的商业计划书，..."）
- 【推断】= 基于行业知识或专业判断推理的，标【推断】并附推导依据（如"...处于亏损阶段【推断：...】"）

不出现【待核验】。查不到的要么推断（标【推断】+推导依据），要么不写。

## 写作要点速记

- **证据三级标注**：每个数据标【已查证】/【企业自述】/【推断】，不出现【待核验】。推断必附推导依据。
- **保密提示**必出现在导语；**落款机构+日期**必出现于文末。
- **数据具体化**：金额、比例、产能、产值、倍数写到数值与年份，避免"较大/较高"。
- **算式外显**：产值÷市场规模、营收×倍数这类对撞测算写出算式，增强说服力。
- **推断可复现**：标【推断】的推导链要完整，读者能跟着推导过程算出同样结论。
- **盲区不散落**：查不到也推不了的维度，不在基本情况留空，而是影响研判的在研判部分标盲区+会面核实建议。
- **事实判断分层**：基本情况不掺判断，初步研判不脱离前文事实与推断。
- **结论可执行**：评级 + 具体下一步 + 会面核实要点，不写空话。
- **政策依据**：结论段引用"以投促招"工作方案与筛选标准。
