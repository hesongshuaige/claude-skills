# CYBGUP — 国资以投促招项目初步研判报告

## 概述

用于见企业前的预判：基于BP + 联网搜索 + 行业推断，按20个维度研判，输出专业级初研报告。不等企业补料，用查证+推断+专业知识把判断做完。

## 核心特性

- **三层验证引擎**：查证（浏览器优先搜索）→ 推断（行业知识推导，标【推断】+推导链）→ 盲区（关键维度标盲区+会面核实建议）
- **浏览器优先搜索**：Playwright/Chrome 优先 → HTTP 请求库次选 → 搜索引擎兜底，穷尽6种搜索策略
- **估值方法论**：可比公司 PS/PE + DCF 情景分析（熊/基/牛三档 + 敏感性矩阵）
- **竞争格局模板**：五列对比表（定位/用户/优势/威胁判断）
- **三级证据标注**：【已查证】/【企业自述】/【推断】，不出现【待核验】
- **国标公文导出**：一键转 GB/T 9704-2012 公文 Word

## 快速使用

```
# 在 Agent 中触发
你用CYBGUP处理一下这份BP：[附件]
```

## 依赖

- Python 3.10+
- python-docx（公文 Word 导出）
- 推荐安装 playwright-core（浏览器优先搜索）

## 适用场景

- 诸葛基金 / 武发基金 / 武侯国资"以投促招"项目研判
- 见企业前的快速预判
- 投前初筛
- 招商项目评估
- 反向校验与打假

## 评级体系

| 评级 | 含义 |
|------|------|
| A 建议推进 | 业务清晰、数据可信、估值合理 |
| B 谨慎跟进 | 有亮点但需会面核实关键信息 |
| C 储备观察 | 暂不进实质流程，长期观察 |
| D 暂缓 | 当前不具备推进条件 |
