# 企业材料识别指南

> 本指南用于 touyan 研判流程 Step 0，帮助 AI 自动识别企业提供的资料类型，
> 并根据类型决定如何使用其中的数据。
> 触发条件：用户上传任意文件后，在分析前先读取本指南进行识别。

---

## 文件类型识别矩阵

| 文件名关键词 | 文件内容特征 | 识别结果 | 数据使用指引 |
|------------|------------|---------|-----------|
| `审计报告` `审计` `annual report` | PDF，含会计师事务所签章，多年数据并排 | **审计报告** | 高置信度；直接引用财务数据；提取营收/利润/资产关键科目光年对比 |
| `BP` `商业计划书` `business plan` | PPT/PDF，含估值诉求、融资历史、团队介绍 | **商业计划书** | 低置信度；用于了解企业战略定位和估值预期；财务预测不引用 |
| `项目方案` `投资方案` `融资方案` | Word/PDF，含交易结构、投资金额、退出路径 | **项目方案** | 中置信度；用于了解企业诉求；条款可行性需独立判断 |
| `合同` `协议` `agreement` | PDF，含甲乙方签章、权利义务条款 | **合同文本** | 高置信度（已发生事实）；用于核实业务关系、关联交易、特殊条款 |
| `财务报表` `利润表` `资产负债表` | Excel/PDF，无审计签章 | **内部财务报表** | 低置信度；需标注"未经审计"；可作为趋势参考但不能作为定论 |
| `招股书` `IPO` `上市申报` | PDF，证监会/交易所格式，含大量行业数据 | **招股书** | 高置信度（证监会审核）；直接引用；行业数据部分标注来源 |
| `专利` `知识产权` `软著` | PDF/网页截图，含证书编号、申请时间 | **知识产权证明** | 中置信度；核实真实性（可通过国家知识产权局官网核验） |
| `资质` `认定` `证书` `专精特新` | PDF/截图，含官方签章 | **资质认定文件** | 高置信度（官方认定）；核验有效期和编号 |
| `会议纪要` `访谈记录` `尽调` | Word，含时间/人员/讨论内容 | **访谈/会议纪要** | 低置信度（一方记录）；用于补充背景；不作为承诺依据 |
| `新闻稿` `PR` `媒体报道` | 网页/PDF，含媒体来源和日期 | **新闻稿** | 低置信度；用于核实事件发生；不用于数据引用 |

## 自动识别流程

```
Step 1: 读取文件名，匹配"文件类型识别矩阵"
Step 2: 如文件名不明确，扫描文件前200字内容特征
Step 3: 输出识别结果（类型 + 置信度初判）
Step 4: 进入对应"数据使用指引"处理流程
```

---

## 内容结构识别（针对审计报告）

**审计报告必含要素**（用于与普通财务报表区分）：

```
✅ 有会计师事务所名称 + 注册会计师签章
✅ 报告文号（如"XY审字〔2025〕第A001号"）
✅ 合并资产负债表、利润表、现金流量表、所有者权益变动表
✅ 附注章节（对主要科目的解释）
✅ 意见类型：无保留意见 / 保留意见 / 否定意见 / 无法表示意见
```

**若无以上要素**，识别为"内部财务报表"，置信度降为低。

---

## 多文件关联识别

当用户上传多个文件时，按以下优先级建立关联：

1. **审计报告优先**：同一数据点以审计报告为准
2. **合同核实业务**：业务关系、收入确认方式以合同为准
3. **BP 核实诉求**：估值预期、融资条件以 BP 为准（但需交叉验证）
4. **新闻稿核实事件**：具体事件发生时间以新闻稿为准

## 常见误识别案例

| 实际情况 | 误识别为 | 正确识别 | 风险 |
|---------|---------|---------|------|
| 企业发的 Word 格式财务报表 | 审计报告 | 内部财务报表 | 误当高置信度数据使用 |
| 商业计划书含审计数据截图 | 审计报告 | 商业计划书 | BP 中数据可能有选择性截取 |
| 投资意向书（含条款） | 正式合同 | 意向书 | 条款无法律约束力，不作为承诺 |
| 企业官网截图 | 官方资料 | 企业自述 | 降为低置信度 |
| 天眼查导出的工商信息 | 工商原始数据 | 第三方平台数据 | 标注来源，可引用但非政府官网直查 |
