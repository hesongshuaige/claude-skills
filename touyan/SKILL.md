# 企业投资研判标准流程

## 模式选择

**触发后第一件事：询问用户选择模式。**

向用户提问："要快速看看还是出正式研判报告？"

- **快速模式**：对话式回答，不出文档。搜索2-3次，覆盖公司概况+核心风险+一句话建议。像同事聊天一样给意见，用户可以追问。
- **完整模式**：走全部阶段，出正式研判报告（docx），按下方完整流程执行。

如果用户已有明确意图（如"帮我出一版研判报告""正式分析一下"），直接进入完整模式，不重复询问。

### 报告受众与深度调整

完整模式的报告默认面向**投资委员会+上级领导**，兼顾决策效率和合规审查。若用户明确指定受众，按以下规则调整：

| 受众 | 深度调整 |
|------|---------|
| 投资委员会/风控部 | 标准深度，量化指标完整，合规段落详写 |
| 公司领导（非投委会） | 核心判断和风险前置，技术细节简化，结论更口语化 |
| 街道办/政府部门 | 突出产业匹配和招商价值，投资术语加注释 |
| 内部团队讨论 | 可适当简化格式，侧重分析逻辑而非排版 |

若用户未指定受众，按"投委会+领导"标准出报告，不额外询问。

### 合规边界

- 报告仅供内部使用，末尾已含"请贵单位内部掌握，勿提供至公司或其他方"声明
- 不得在报告中承诺投资收益或做出保本暗示
- 涉及未公开信息时标注"内部资料，不得外传"
- **外部动作边界**：公开检索、草拟报告、生成本地文件可直接执行；上传飞书、发送给第三方、修改外部知识库或使用付费数据源，必须先得到用户明确确认

## 铁律

1. **企业提供的资料是一手数据，公开搜索是二手信息。一手 > 二手。**
2. **企业数据默认置信度"低（待验证）"，除非有独立第三方审计报告背书。**
3. **企业说什么先记录，不轻信。能验证的验证，验证不了的标注"待核实"。严禁推测性填充。**
4. **结论必须明确：投/不投/有条件推进。严谨使用"各有优劣""建议进一步了解"等模糊话术。**
5. **同一项目只出一个结论。** touyan 主控结论确定后，Excel/PPT/其他附件必须与之严格匹配。
6. **数据矛盾必须选边。** 企业BP数据与第三方权威数据冲突时，禁止并列呈现后让读者自判断。分析师必须选一个数据源并说明选择理由（来源可靠性/统计口径/可验证性三选一），标注置信度。严禁"双方数据均列示，请读者自行判断"。
7. **信息缺失必须分级。** 任何报告都必须包含信息缺失分级表，即使无信息缺失也须注明"无"，不得省略。P0级缺失即触发项目终止条件，不上会、不进入决策讨论。
8. **退出路径必须量化。** 退出分析不得止于定性描述，必须包含情景DPI表（乐观/基准/悲观/清算四情景+概率加权综合DPI），可用条件估算但不得留空。DPI<1.0时必须标注本金亏损风险。
9. **交易条款的数字必须有推导链路。** 对赌业绩、回购利率、反投比例——每个数字必须写出"参照XX数据/按XX逻辑推算"，不得凭空给数字。严禁"建议对赌线8000万"而不说为什么是这个数字。
10. **"全国首创/唯一/领先/首发/率先"等自述必须与专利/认证清单交叉核验（操作化定义）。**
    - **核验数据源**：国家知识产权局专利检索系统（https://pss-system.cponline.cnipa.gov.cn，免费注册可查），辅以企查查/天眼查专利字段（后者仅作快速参考，不作为最终依据）
    - **专利口径**：仅统计"已授权且法律状态有效"的**发明专利**（不含实用新型、外观设计、软件著作权）
    - **阈值触发规则**：BP自述"全国首创/唯一/领先"次数 > 发明专利数量 × 2 → 触发"密度落差"标注
    - **举例**：发明专利3项 + BP自称首创10处 → 3×2=6 < 10 → 触发
    - **不得用"待核实"模糊处理**：核验动作必须执行并给出结论

## 数据来源优先级

1. 用户上传的企业资料（BP、财务报表、审计报告、合同等）
2. 用户上传的第三方报告（券商研报、行业报告等）
3. 公开搜索结果（新闻、公告、统计数据）

用户上传文件时，自动识别文件性质（审计报告/BP/项目方案/合同等），无需用户分类。提取其中的关键数据，与公开搜索结果交叉比对，矛盾处标注。

**来源冲突处理规则（从CYBG融合）**：
- 监管文件、工商/法院公告、年报/招股书优先于企业BP
- 政府文件和交易所材料优先于媒体报道
- 企业官网/公众号可证明企业自述但不能单独证明业绩真实性
- AI生成内容、无出处截图、口头传闻只能作为线索，不能进入关键结论
- 来源冲突无法解决时，正文必须写明冲突点、采用口径和待核实问题

**数据源等级（从CYBG融合，用于证据台账）**：
- **S1（最高）**：监管文件/招股书/年报/法院公告/工商平台
- **S2（高）**：权威行业报告/政府文件/交易所问询
- **S3（中）**：主流财经媒体/企业官网/官方公众号
- **S4（低，仅线索）**：行业自媒体/二手转述。**禁止**：百度知道、无出处截图、"据传"类

## 执行策略（按企业阶段调整）

| 阶段 | 判断依据 | 公开信息覆盖 | 企业材料依赖 |
|------|---------|:---:|:---:|
| 成熟期 | 已上市或已递交招股书 | 70-80% | 20-30% |
| 成长期 | 有多轮融资记录 | 50-60% | 40-50% |
| 早期 | A轮前，网上痕迹少 | 30-40% | 60-70% |
| 传统国企 | 非上市国有/央企 | 30-40%（工商/舆情有，财务无） | 60-70% |

## 阶段1：材料处理 + 证据台账

读取用户上传文件后，按以下判断树自动识别文件性质（无需用户告知文件类型）：

```
文件内容判断顺序：
1. 有"资产负债表""利润表""现金流量表" → 财务报告（进一步判断是否有审计意见）
   └─ 附"审计报告"或"注册会计师审计"字样 → 审计报告 → 置信度：高
   └─ 无审计字样 → 内部财务报表 → 置信度：低（待核实）
2. 有"商业计划书""BP""Business Plan" → BP文件 → 置信度：低（企业自述）
3. 有"项目方案""投资建议书""可行性研究报告" → 招商/投资方案 → 置信度：低
4. 有"投资协议""股权转让""增资扩资" → 合同/法律文件 → 置信度：高（条款约束）
5. 有"股权结构""股东名册""工商信息" → 股权文件 → 置信度：中（可与工商数据交叉验证）
6. PDF扫描件无文字层 → OCR识别；识别失败 → 标注"无法提取，置信度：缺失"
```

**置信度初判原则**：
- 审计报告（有CPA签章）→ 高
- BP/项目方案/内部财务表 → 低（企业自述，未经独立核实）
- 合同/法律文件 → 中高（条款有法律约束，但不代表商业可行性）
- 交叉验证：同一数据点出现在两份不同性质文件（如BP和审计报告）→ 升一级

**同文件类型内部置信度分层（优先级从高到低）**：
同一企业提供的BP，置信度按以下标准递减：
1. **经审计的财务数据**（有事务所盖章）> 未经审计的管理层财务数据
2. **附具体订单合同号的收入确认** > 概括性收入描述
3. **有第三方验证节点的进展**（如政府批文、资质认证）> 纯企业自述
4. **正式版BP（含签章）** > 交流版PPT > 口头承诺/微信记录（后者不作为正式依据，仅供参考）
5. **最新版BP** > 旧版BP（若两版数据不一致，以最新版为准，但旧版数据标注"已被替代，待核实"）

若同一数据点在企业提供的多份文件中出现且数字不一致：以最高置信度版本为准，同时在正文脚注中注明差异和选择理由。

**注意**：BP中政府项目预算不等于公司可落地的合同金额。若BP提及"某省政府投资X亿"，必须追问公司实际可获取份额、是总包还是分包、有无白纸黑字的合作框架协议。

### 证据台账（从CYBG融合，核心新增）

所有影响结论的数据和事实必须进入证据台账。报告正文可以简化展示，但台账必须保留到数据来源汇总表或附录。

| 事实/数据 | 数值或结论 | 来源等级 | 来源名称 | URL/文件页码 | 数据日期 | 访问日期 | 置信度 | 用途 |
|----------|------------|----------|----------|-------------|----------|----------|--------|------|

**置信度规则**：S1且多源一致=高；S2或S3单源=中；S4或无法复核=低。**低置信度信息不得作为投资建议的唯一依据。**

**结论约束**：若核心结论依赖企业BP单方数据，置信度最高为"中"；若估值、客户订单、实控人或重大合规任一项低置信度，投资建议不得高于"暂缓跟进/建议培育"。

## 阶段2：公开信息搜索

### 搜索工具优先级

**Tavily（AI摘要+全文提取）> Serper（Google搜索结果）> web_fetch（页面抓取）**

### 标准搜索流程

**快速模式：2-3次搜索**（只覆盖搜索1+搜索4，必要时加搜索2）
**完整模式：不超过8次搜索**，每次搜索覆盖一个独立维度，搜索完立即提取数据并录入证据台账。

如果用户已上传企业资料，先读取资料提取数据，再做以下搜索补充和验证：

**搜索1：工商+股权+融资+资质**
- 关键词：企业名 工商信息 股权 融资 专精特新
- 目标：企查查/天眼查聚合页、国家企业信用信息公示系统、百度百科
- 提取：工商基本信息、股权结构、实控人、融资历史、资质荣誉、专利数量

**搜索2：主营业务+行业分析+市场规模**
- 关键词：企业名 主营业务 行业分析 市场规模
- 目标：行业报告、公司官网、36氪/虎嗅等行业媒体
- 提取：主营业务描述、行业地位、竞争格局、市场规模估算
- **交叉验证**：市场规模至少2个独立源交叉验证

**搜索3：财务数据+可比公司估值**
- 关键词：企业名 财务数据 可比公司 PS PE 估值
- 目标：IT桔子/清科数据、上市招股书财务章节、交易所问询函
- 提取：营收/利润规模、可比公司PS/PE区间、融资估值历史

**搜索4：法律诉讼+行政处罚+负面舆情**
- 关键词：企业名 诉讼 处罚 被执行人 负面
- 目标：裁判文书网、中国执行信息公开网、天眼查法律风险栏
- 提取：诉讼记录、行政处罚、失信被执行人、负面新闻
- 无负面结果时明确说明"公开渠道未发现"

**搜索5：上市进展+退出路径+可比交易**
- 关键词：企业名 IPO 上市 退出 并购 收购
- 目标：证监会公示、交易所公告、并购重组报告、财经媒体
- 提取：上市辅导/申报进展、近期可比并购交易、退出路径参考

**搜索6：创始人背景深挖（从CYBG融合，新增）**
- 关键词：创始人名 创业经历 公司名
- 目标：天眼查/企查查关联企业、行业媒体报道、学术/专利检索
- 提取：完整创业履历、之前公司状态、退出经验、技术路径延续性
- **每条标注来源平台**。搜不到写"公开信息未检索到，建议面谈核实"

**搜索7：供应链与认证门槛（从CYBG融合，新增）**
- 关键词：企业名 供应商 产业链 行业准入 资质
- 目标：行业协会、上下游企业公告、政策文件
- 提取：供应商格局、供应商延伸风险、行业准入资质要求

**搜索8：政策环境（从CYBG融合，新增）**
- 关键词：行业名 政策 补贴 准入门槛
- 目标：国务院/部委/省级政府发文、地方经信局
- 提取：相关政策、准入门槛、补贴政策
- **时效性要求**：政策超过24个月未更新须提示"可能过时"

### 搜索效率铁律
- **8次已覆盖主要维度**，仍有信息缺口时 → 在报告中声明"数据缺失"，不凑数搜索
- **搜到聚合页时用 web_fetch 深入抓取**，而不是换个引擎再搜

**搜索局限性声明（强制）**。本框架依赖公开可核实信息，以下内容无法通过公开搜索覆盖，分析师须在信息缺失分级表（P1/P2）中明确声明：
- 未公开的融资条款细节（投资协议核心条款、估值调整机制、对赌公式）
- FA渠道信息、私募融资的非公开报价
- 地方政府隐形承诺或未经公开披露的合作意向
- S基金报价、私募二级市场流动性数据
- 依赖"知情人士""接近监管层"等未署名消息源的内容

**时效性处理（从CYBG融合，新增）**：
- 工商、诉讼、经营异常、上市公司市值/财务、融资进展必须尽量检索最新公开版本，并记录访问日期
- 市场规模、政策、行业报告超过24个月未更新时必须提示"可能过时"并尝试找更新来源
- 政策、监管、IPO审核、诉讼等易变事项超过6个月未核验不得作为高置信度依据

### 子任务使用边界
- **单企业研判**（本 skill 场景）：主 session 串行搜索，不派子任务
- **多企业横向对比/批量调研**：派子任务并行，子任务各自独立搜索，主 session 汇总
- **行业背调**：派子任务，走 deep-research 流程

### 异常场景处理

| 场景 | 处理方式 |
|------|---------|
| 搜索完全无结果 | 声明"公开信息极度匮乏"，建议用户提供材料或确认名称。不出完整报告，降级为快速模式 |
| 企业名称不明确 | 先确认企业全称再搜索，不猜测 |
| 用户上传的文件无法解析 | 标注"文件无法提取"，尝试OCR，失败则声明缺失 |
| 数据全部来自企业自述 | 所有数据标注"置信度：低（待核实）"，声明"本报告置信度受限" |
| 用户要求跳过某些维度 | 可跳过P2维度但必须说明影响。P0维度不可跳过 |

## 阶段3：分析与研判

按以下分析维度逐项研判，正反都说，风险按严重程度排序：

### 分析维度清单

**算账维度（对应报告"估值与交易结构"部分）：**
1. 投资方案与反投核算：拟投金额、持股比例、估值依据、反投比例、账算得平不平
2. 落地路径与产值测算：落地后营收路径，有无确定订单/合同，分年度测算
3. 对赌设计：对赌标的合理性（对照历史数据）、退出机制、回购义务人偿付能力
4. 可比公司对标：2-3家可比公司，PS/PE对比，标的企业估值在区间中的位置。竞对财务须有一级源确认

**企业质量维度（对应报告"公司研判"部分）：**
5. 股权与控制权：股东结构、实控人、表决权穿透、交易对手是否有决策权
6. 关联交易与独立性 ★一票否决：关联方营收/采购占比，>40%高度警惕
7. 客户集中度：前5客户占比，>30%需关注，>85%极度脆弱
8. 财务健康度：营收趋势、毛利率、亏损趋势、现金储备、净资产为负→硬伤
9. 供应链风险：核心技术/原材料是否受制于人
10. 行业地位与竞争格局：市占率、排名、增速天花板、护城河还是集成商。垂直整合检查：最大下游是否自研同类产品
11. 团队背景：行业经验、近期变动、利益冲突

**退出与合规维度（对应报告"初步研判"相关部分）：**
12. 上市进展与退出路径：IPO状态、逐路径概率加权DPI
13. 法律风险 ★一票否决：诉讼、失信、股权冻结、行政处罚、子公司异常
14. 国资合规核检 ★一票否决：资产评估(33号令)、进场交易(32号令)、关联交易决策、对赌可执行性、政府投资基金限制、明股实债/变相保底

**政府视角维度（对应报告"公司研判"相关部分）：**
15. 武侯区产业匹配度：产业匹配、政策支持、反投自检
16. 舆情与负面信号：只关注负面预警，不堆砌正面宣传

**信息可信度维度（对应报告"信息瓶颈声明"部分）：**
17. 企业提供资料清单：提供了什么、核心数据来源是什么
18. 信息盲区与致命性评估：P0/P1/P2分级+核实主体+期限+未通过处置

### 写作风格铁律（经过多轮用户反馈校准，必须严格遵守）

1. **段落式叙述，不是表格堆砌。** 二级标题下是连贯段落，像同事写的分析报告
2. **标题要有判断，不要中性标签。** "应急产业政策明确但格局分散"优于"行业分析"
3. **结论区和正文不重复。** 结论区只放判断和条件，正文才展开
4. **置信度标注轻量化。** 正文流畅叙述，只在关键分歧点标注
5. **国资合规写成段落，不写成清单。** 逐条打钩只存在于分析过程中
6. **数据置信度评分卡只在信息瓶颈明显时出现**
7. **字数由信息量决定。** 只有会议纪要：4000-5000字。有完整招股书：6000-8000字
8. **保留过渡词。** "但需关注的是""值得注意的是"是标准件
9. **标题面面俱到是优势。** 兼顾正反两面是惯例，不是和稀泥
10. **技术翻译。** 所有术语用大白话类比翻译。不说"技术先进"，说"同行做不到XX，这家能做到，差距在于..."

## 阶段4：输出

### 快速模式输出

不出文档，直接在对话中回答。格式要求：

1. **开头一句话结论**：这家公司值不值得关注，用大白话
2. **公司概况**：做什么的、多大、什么阶段，2-3句话
3. **核心发现**：最关键的2-3个点
4. **最大风险**：一句话说清楚最可能翻盘的问题
5. **下一步建议**：如果要继续推进，最需要核实什么

**快速模式护栏**：
- 结论必须明确，不能用"各有优劣"糊弄
- 数据来源必须说明
- 搜索不足时必须声明局限性
- 禁止给出具体投资金额建议、对赌数字
- 发现P0级风险必须立即提醒

### 完整模式输出

#### 报告结构

**标题区：**
```
成都诸葛私募基金管理有限公司关于
[企业全称]
项目的初步研判
```

**核心判断（标题下方、正文之前，加粗，一到两句话）：**
```
有条件推进，建议纳入B类项目，立项尽调。核心条件：投前估值≤X亿元，
投资≤X万元，附对赌回购条款。
```

**执行摘要（200字以内）：**
```
本项目建议[有条件推进/不推进/终止]，核心支撑逻辑：[一句话说明1]，[一句话说明2]。
最大风险点：[最可能翻盘的风险，1句话]。
建议立项前提：[最重要的1个P0核实项]。
```

**【P0预警占位符】**
若存在任何P0级信息缺失，须用一句话预警。无P0缺失则注明"无P0缺失，本项目可提交立项讨论。"

**开头段：**
```
晋阳街道：

根据[时间/场合]诸葛资本公司拜访/调研[企业全称]（以下简称[简称]或公司）的
交流情况[及企业提供的XX资料]，结合公开工商信息、行业资料等综合要素，现形成
初步研判报告如下，请贵单位内部掌握，勿提供至公司或其他方。
```

**基本情况（客观叙述，不判断）：**
- **工商信息**：一段话
- **股权结构及对外投资**：一段话
- **实控人及核心团队**：一段话 + **【团队网络信息核验（强制）】**
  - 失信与限高核验→关联企业异常→负面信号，3步按顺序执行
  - 核验结论写在团队段落末尾
- **主营业务**：做什么→做得怎么样→在武侯做了什么，三层递进
- **财务与经营情况**：一到两段
- **融资及落地计划**：一段话

**初步研判（带观点的分析，核心部分）：**
- **行业研判**（1-2段）
- **公司研判**（2-3段）：优势→风险→反投自检→招商决策结论（二选一明确）
- **估值与交易结构**（1-2段）：估值校准→交易结构建议→退出路径DPI量化表

  **【国资合规段落占位】**：本节末尾须有合规检查结论段落

  **退出路径DPI量化方法论（强制）：**
  - 锚定可比交易→建立PS情景矩阵→计算回收金额→标注置信度
  - DPI量化表（乐观/基准/保守/回购/清算+概率加权综合）
  - 锚点PS倍数参考：本地PS库 > A股并购 > 一级市场 > IT桔子/清科
  - 对赌推导链路、回购利率推导、反投比例量化（均强制）

- **信息瓶颈与致命性评估**（必须出现）：
  - P0/P1/P2分级表格
  - BP首创密度与专利储备对比
  - 致命等级定义：P0=终止、P1=降级/终止、P2=补充

**落款：**
```
成都诸葛私募基金管理有限公司
YYYY年MM月DD日
```

## 阶段5：自检 + 3轮迭代（从CYBG融合，核心优化）

### 交付质量门（从CYBG融合，新增）

完整模式按3轮制执行，每轮有明确的质量门：

**第1轮（阶段1-3）→ 质量门**：
- P0缺失项未解决 → 只能输出信息缺口和待核实问题，**不生成投资建议**
- P1缺失项较多 → 可生成初稿但必须降低置信度
- **等用户确认后进入第2轮**

**第2轮（阶段4）→ 质量门**：
- 按框架撰写完整报告
- 执行下方自检清单
- 输出报告摘要+关键数据请用户核实
- **等用户反馈后进入第3轮**

**第3轮（迭代优化）→ 收敛**：

| 反馈类型 | 处理方式 |
|---------|---------|
| 数据补充 | 插入新数据，联动重评（估值→DPI→建议→招引） |
| 判断修正 | 先改依据再重新推导结论 |
| 数据核实 | 逐项搜索验证，标注核实状态 |
| 风格优化 | 术语全部翻译成大白话 |
| 模糊改进 | 按数据→结论→术语→红绿旗→招引顺序自检 |

**收敛提示**：连续2轮只改风格无实质变化→提醒定稿。迭代超过5轮→提醒"核心框架已稳定，建议定稿后面谈补充"。

### 自检清单

每份报告在提交前，对照以下清单逐项确认。任何一项未通过→报告不得提交。

**铁律执行核查**：
- [ ] 结论明确，结论区只有判断和条件
- [ ] 数据矛盾已选边并说明理由
- [ ] 信息缺失已分级（P0/P1/P2表）
- [ ] 退出DPI已量化（五情景+置信度）
- [ ] 交易条款数字有推导链路
- [ ] "全国首创"自述与专利数已对比
- [ ] 政府项目预算已拆分

**证据台账核查（从CYBG融合，新增）**：
- [ ] 关键事实已进入证据台账，能追溯到URL/文件页码
- [ ] 数据来源等级标注正确（S1-S4）
- [ ] 时效性标注清楚：易变信息有访问日期，过时信息已提示
- [ ] 低置信度信息未作为投资建议的唯一依据

**结构完整核查**：
- [ ] 核心判断一句话，领导30秒抓住要害
- [ ] 行业数据已明确数据源
- [ ] 公司研判含招商决策结论
- [ ] 交易结构含条款设计
- [ ] 国资合规已审查

**写作规范核查**：
- [ ] 标题有判断
- [ ] 正文无表格堆砌
- [ ] 国资合规是段落
- [ ] 过渡词保留

### 验收标准

**验收人：用户（何松或其指定人员）为最终验收人。**

**AI自检评分（提交前自评，附在报告末尾）：**

| 维度 | 权重 | 评分（1-5） | 说明 |
|------|------|------------|------|
| 结论明确性 | 25% | — | 投/不投/有条件推进，无模糊话术 |
| 数据可靠性 | 25% | — | 来源标注清晰，矛盾已选边，台账可追溯 |
| 风险覆盖度 | 20% | — | P0/P1风险无遗漏，致命性评估到位 |
| 量化完整性 | 15% | — | DPI表、对赌推导、估值参照齐全 |
| 合规安全性 | 15% | — | 国资合规逐项有结论，无保底/承诺收益 |

**评分标准**：≥4.0（80分）可提交；3.5-3.9可提交但说明短板；<3.5打回修改

**快速模式验收（简化版）**：自问3个问题：结论明确吗？最大风险说了吗？数据来源区分了吗？

## 阶段6：国资合规核检

使用 `references/国资合规检查清单.md` 逐项执行合规检查，输出时合并为连贯段落。

**核心判断标准（必须掌握，不得以"需法务审查"一笔带过）：**

- **33号令（资产评估）**：单笔投资超净资产5%或绝对值超500万元→必须评估
- **明股实债三种形式**：①本金+固定收益兜底 ②强制分红条款 ③第三方代偿本息
- **回购条款触发条件**：建议以业绩指标或融资节点触发，避免纯时间触发被认定为固定回报
- **变相保底红线**：禁止承诺最低收益、保证本金安全
- **关联交易**：须确认已履行决策回避和披露程序

## 复盘沉淀（从CYBG融合，新增）

每次第3轮后，若出现以下情况，更新本技能的参考文件：
- 同类行业反复缺少关键指标 → 补充到行业专属项
- 同类返工超过2次（估值口径、MOIC公式、招商话术反复出错）
- 用户确认某类表达更符合领导口径 → 沉淀为写作风格规则
- 政策、监管、数据源发生明显变化

**不要**把单个项目的商业秘密、未公开数据或领导个人意见直接沉淀进公共技能；只能抽象成通用规则或脱敏模板。
