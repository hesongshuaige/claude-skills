# 财务分析框架

> 本框架用于 touyan 研判流程阶段3，提供系统化的财务分析方法论。
> AI 按企业阶段选取适用指标，不是每项都必须算。

---

## 一、财务比率分析清单

### 1. 盈利能力

| 指标 | 公式 | 健康信号 | 预警信号 |
|------|------|---------|---------|
| 毛利率 | (营收-成本)/营收 | >30%且稳定/上升 | <15%或连续下滑 |
| 净利率 | 净利润/营收 | >10%（成熟企业） | 持续为负且无收窄趋势 |
| EBITDA利润率 | EBITDA/营收 | >20%（制造业） | 行业均值以下且恶化 |
| ROE | 净利润/净资产 | >15% | <5%或负值 |

**注意**：早期企业（A轮前）净利润为负是常态，重点看毛利率趋势和亏损收窄速度。

### 2. 偿债能力

| 指标 | 公式 | 健康信号 | 预警信号 |
|------|------|---------|---------|
| 资产负债率 | 总负债/总资产 | <60% | >80%或持续上升 |
| 流动比率 | 流动资产/流动负债 | >1.5 | <1.0（短期偿债压力大） |
| 速动比率 | (流动资产-存货)/流动负债 | >1.0 | <0.5 |
| 净资产 | 总资产-总负债 | 正值且增长 | 为负→硬伤 |

**关键判断**：净资产为负 = 资不抵债，属于铁律中的硬伤，直接在报告中标红。

### 3. 运营效率

| 指标 | 公式 | 解读 |
|------|------|------|
| 应收账款周转天数 | 365×应收账款/营收 | >90天需关注回款风险 |
| 存货周转天数 | 365×存货/成本 | 行业差异大，看趋势 |
| 经营性现金流/净利润 | 经营现金流/净利润 | <0.5说明利润质量差 |

**核心逻辑**：利润可以调，现金流难造假。经营现金流持续为负比亏损更危险。

### 4. 成长性

| 指标 | 公式 | 解读 |
|------|------|------|
| 营收增速 | (本期-上期)/上期 | 连续3年>20%=高成长 |
| 利润增速 | (本期-上期)/上期 | 营收增但利润不增=增收不增利 |
| 人均产出 | 营收/员工数 | 横向对比同行业 |

## 二、估值方法论

### 估值方法选择指南

| 企业阶段 | 首选方法 | 辅助方法 | 不适用 |
|---------|---------|---------|--------|
| 早期（无收入/微利） | 最近一轮融资估值 | 可比公司PS（用前瞻营收） | DCF、PE |
| 成长期（有收入，利润不稳定） | PS倍数法 | 可比交易法 | PE、DCF |
| 成熟期（稳定盈利） | PE倍数法 + DCF | 可比交易法、PS | — |
| 重资产（制造业/基础设施） | PB倍数法 + DCF | 资产基础法（NAV） | PS |

### PS倍数法操作步骤

1. 找2-3家可比上市公司/近期交易
2. 提取其PS倍数（市值/营收 或 交易对价/营收）
3. 计算区间：中位数 + P25/P75
4. 结合标的企业增速调整（增速高于可比 → 取偏上区间）
5. 标的企业估值 = 预测营收 × 选取PS倍数
6. **必须说明选取理由**，不能只给一个数字

### PE倍数法操作步骤

1. 找2-3家可比公司
2. 提取PE倍数（动态PE，用预测净利润）
3. 对标的企业净利润做调整（扣除非经常性损益）
4. 标的企业估值 = 调整后净利润 × 选取PE倍数

### DCF适用说明

- **适用**：有稳定现金流预测的成熟企业（C轮后/盈利企业）
- **不适用**：早期亏损企业（预测现金流不靠谱）
- 若使用DCF，必须给出WACC假设和终值假设
- DCF结果仅作参考区间，不作为唯一定价依据

### 可比交易法

- 参考近期（2年内）同行业并购/融资交易对价
- 提取交易PS/PE倍数
- 注意交易时点差异（市场热度不同）
- 至少找到1笔可比交易才可信，否则声明"可比交易数据不足"

## 三、退出路径量化升级

### DPI 框架（已有，保持不变）

五情景：乐观/基准/保守/回购/清算 + 概率加权综合DPI

### IRR 计算方法（新增）

**IRR（内部收益率）= 使投资净现值为零的折现率**

操作步骤：
1. 列出预计现金流：投资时点 -X万，退出时点 +Y万
2. 若有中间分红，加入对应年份
3. 用Excel的IRR函数或试算法计算
4. **基准要求**：IRR > 15%才值得推进（PE行业一般门槛）

情景IRR表：

| 情景 | 预计退出时间 | 退出金额 | IRR | 概率 |
|------|------------|---------|-----|------|
| 乐观 | 3年 | X万 | XX% | 20% |
| 基准 | 5年 | X万 | XX% | 50% |
| 保守 | 7年 | X万 | XX% | 20% |
| 回购 | 触发时 | 本金+X% | XX% | 5% |
| 清算 | — | 残值 | XX% | 5% |
| **加权综合** | | | **XX%** | 100% |

### MOIC 计算方法（新增）

**MOIC（资本倍数）= 退出金额 / 投资金额**

- MOIC = 1.0x → 刚好回本
- MOIC = 2.0x → 翻倍（PE及格线）
- MOIC = 3.0x+ → 优秀

DPI vs MOIC 区别：
- **DPI**：考虑时间价值，是LP最关心的指标
- **MOIC**：不考虑时间价值，是GP看项目质量的标准

报告中两个都算，DPI为主表，MOIC为辅助。

### 退出路径概率评估参考

| 退出路径 | 适用条件 | 参考概率区间 |
|---------|---------|------------|
| IPO | 已进入辅导期/有明确上市计划 | 20-40% |
| 并购退出 | 行业整合活跃、有战略买家 | 15-30% |
| 股权转让 | 有后续轮次投资人 | 10-20% |
| S基金接转 | 基金到期临近、资产质量尚可 | 5-10% |
| 回购 | 对赌触发、创始人有偿付能力 | 10-20% |
| 清算 | 项目失败 | 5-10% |

**注意**：概率总和必须=100%，不得遗漏路径。每种路径都要估算退出金额和IRR。

## 四、财务数据缺失时的处理

| 缺失类型 | 处理方式 |
|---------|---------|
| 无审计报告，只有BP数据 | 所有财务指标标注"企业自述，置信度：低"，不给具体倍数估值 |
| 有营收无利润 | 只用PS估值，声明"盈利能力待验证" |
| 有利润无现金流 | 加重分析利润质量，经营现金流/净利润比 |
| 完全无财务数据 | 不做估值分析，声明"财务数据缺失，估值区间无法确定"，出条件化测算 |

## 五、报告中的财务分析写法

**不要**：把所有比率列成一张大表塞进报告
**要**：挑最关键的3-5个指标，用段落叙述

示例写法：
```
公司2024年毛利率42%，高于行业均值35%（来源：XX研报），但应收账款周转天数
达120天，回款压力值得关注。经营性现金流/净利润仅0.3，利润含金量偏低。
近三年营收复合增速28%，保持高增长，但净利润增速仅8%，呈现增收不增利特征。
```
