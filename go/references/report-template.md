# 研判报告模板

## I. 研判报告模板

### 报告结构大纲

```
[标题区] {fund_name}关于XX企业项目的初步研判
[核心判断] 加粗，1-2句话，让领导30秒抓住要害
[主送] {recipient}：
[开头段] 根据XX情况，现形成初步研判报告如下...
一、基本情况
  （一）工商信息
  （二）股权结构及对外投资
  （三）实控人及核心团队
  （四）主营业务
  （五）财务与经营情况
  （六）融资及落地计划
二、初步研判
  （一）行业研判（标题带判断）
  （二）公司研判（标题带判断）
  （三）估值与交易结构（标题带判断）
  （四）信息瓶颈声明（仅在信息严重不足时出现）
三、综合研判
[附件] 领导简报短信（日期）
[落款] {fund_name} + 日期
```

### 标题命名规范

- 二级标题必须带判断，不是中性标签
- 格式：核心观点在前，风险在后（例："应急产业政策明确、市场持续扩容，但格局分散"）
- 行业标题：定量+定位+判断
- 公司标题：正负各半，致命风险前置
- 交易结构标题：结论+依据+解决方案

### 写作红线

- 不用"根据目前资料分析来看"这种废话开头
- 不用"总的来说该公司是一家不错的公司"这种模糊判断
- 不用表格堆砌代替段落叙述
- 不在综合研判里重复正文已有的论据
- 结论必须明确（投/不投/有条件推进）
- 标题就是判断，不是中性描述
- 用数据说话（关键数字+来源+置信度）
- 信息缺失必须列P0/P1/P2分级表，无缺失也注明"无"
- 退出路径必须有五情景DPI表
- 交易条款数字必须有推导链路
- 国资合规结论写成段落，不写检查清单
- BP中的政府项目预算不得直接等同于公司收入，必须拆分公司实际合同份额
