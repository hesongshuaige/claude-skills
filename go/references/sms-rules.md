# 领导简报短信生成规则

## F. 领导简报短信生成规则

### 核心原则

- 短信**必须且只能**从已通过质量门禁的研判报告结论中派生，**禁止独立撰写**。
- 所有短信中的数据必须与报告正文严格一致，不得引入报告中未出现的数据或判断。
- 生成时机：报告定稿 + 质量门禁通过之后。

### 短信结构（四段式）

**开头**：
> 董事长，关于XX企业，现将初步研判情况汇报如下：

**一、企业基本情况**（3-5句，关键事实）
- 成立时间、注册资本、所在行业、主营业务一句话概括
- 核心资质（专精特新/高新等）、融资阶段
- 营收规模（有数据就写，没有就写"未提供"）
- 本地落地情况（如有）

**二、主要风险点**（3-4条，按严重程度排序）
- 每条一句话，说清楚"风险是什么"+"影响有多大"
- 最致命的风险放第一条
- 用领导能理解的语言，不用术语

**三、我方初步意见**（结论 + 量化条件）
- 结论必须与报告一致：不投 / 有条件推进
- 如为"有条件推进"，必须写明量化条件（估值上限、对赌条款、投资金额上限）
- 如为"不投"，只说致命问题，不说优点

**四、下一步建议**（1-2句）
- 具体可执行的动作（如"建议安排实地考察""建议调取近两年审计报告"）

**结尾**：
> 以上情况，请董事长阅示。

### 语言约束

- **禁用术语**：DPI、MOIC、PS倍数、IRR、EBITDA、PE倍数（用"估值约X亿元"替代）
- **必用说法**："本金回收风险""年化回报约X%""投资X千万，占股X%"
- **不投结论**：只陈述致命问题，跳过企业优势部分
- **有条件推进**：条件必须量化（如"估值不超过2亿元""对赌业绩不低于5000万净利润"）

### 短信作为报告附件

短信生成后，**同时**作为报告docx的最后一个附件章节插入（位于落款之前）。格式要求：

- 附件标题："附件：领导简报短信（XX年XX月XX日）"，黑体，16.5pt
- 短信正文按仿宋_GB2312排版，首行缩进2字符
- **术语差异说明**（插入在附件标题与短信正文之间）：短信版本已将DPI/MOIC/IRR等专业术语转换为通俗表述，与报告正文含义一致，仅表述方式不同。供直接转发使用。
- 这样领导拿到纸质报告时，最后一页就是可以直接复制发送的短信文本，不用另外找
