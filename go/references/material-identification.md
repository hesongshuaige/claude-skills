# 企业材料自动识别

## D. 企业材料自动识别

### 文件类型识别矩阵

| 识别结果 | 文件名关键词/内容特征 | 置信度 | 数据使用指引 |
|---------|---------------------|--------|------------|
| **审计报告** | 含会计师事务所签章，多年数据并排，报告文号 | 高 | 直接引用财务数据；提取营收/利润/资产跨年对比 |
| **商业计划书(BP)** | 含估值诉求、融资历史、团队介绍 | 低 | 了解战略定位和估值预期；财务预测不引用 |
| **项目方案** | 含交易结构、投资金额、退出路径 | 中 | 了解企业诉求；条款可行性需独立判断 |
| **合同文本** | 含甲乙方签章、权利义务条款 | 高（已发生事实） | 核实业务关系、关联交易、特殊条款 |
| **内部财务报表** | 无审计签章的财务数据 | 低 | 标注"未经审计"；仅作趋势参考 |
| **招股书** | 证监会/交易所格式，含大量行业数据 | 高 | 直接引用；行业数据标注来源 |
| **会议纪要** | 含时间/人员/讨论内容 | 低 | 补充背景；不作为承诺依据 |

### 自动识别流程

```
Step 1: 读取文件名，匹配"文件类型识别矩阵"
Step 2: 如文件名不明确，扫描文件前200字内容特征
Step 3: 输出识别结果（类型 + 置信度初判）
Step 4: 进入对应"数据使用指引"处理流程
```

### 多文件优先级

1. **审计报告优先**：同一数据点以审计报告为准
2. **合同核实业务**：业务关系、收入确认方式以合同为准
3. **BP 核实诉求**：估值预期、融资条件以 BP 为准（但需交叉验证）
4. **新闻稿核实事件**：具体事件发生时间以新闻稿为准

### 常见误识别防范

| 实际情况 | 容易误识别为 | 正确处理 |
|---------|------------|---------|
| 企业发的 Word 格式财务报表 | 审计报告 | 识别为内部财务报表，低置信度 |
| BP含审计数据截图 | 审计报告 | 仍为BP，数据可能有选择性截取 |
| 投资意向书 | 正式合同 | 意向书，条款无法律约束力 |
| 企业官网截图 | 官方资料 | 企业自述，降为低置信度 |
| 天眼查导出工商信息 | 工商原始数据 | 第三方平台数据，标注来源 |
