# 投资研判铁律与快速否决通道

## A. 铁律（10条）

1. **企业提供的资料是一手数据，公开搜索是二手信息。一手 > 二手。**
2. **企业数据默认置信度"低（待验证）"，除非有独立第三方审计报告背书。**
3. **企业说什么先记录，不轻信。能验证的验证，验证不了的标注"待核实"。严禁推测性填充。**
4. **结论必须明确：投/不投/有条件推进。严谨使用"各有优劣""建议进一步了解"等模糊话术。**
5. **同一项目只出一个结论。** touyan 主控结论确定后，Excel/PPT/其他附件必须与之严格匹配。
6. **数据矛盾必须选边。** 企业BP数据与第三方权威数据冲突时，禁止并列呈现后让读者自判断。分析师必须选一个数据源并说明选择理由（来源可靠性/统计口径/可验证性三选一），标注置信度。严禁"双方数据均列示，请读者自行判断"。
7. **信息缺失必须分级。** 任何报告都必须包含信息缺失分级表，即使无信息缺失也须注明"无"，不得省略。P0级缺失即触发项目终止条件，不上会、不进入决策讨论。
8. **退出路径必须量化。** 退出分析不得止于定性描述，必须包含情景DPI表（乐观/基准/保守/回购/清算五情景+概率加权综合DPI），可用条件估算但不得留空。DPI<1.0时必须标注本金亏损风险。
9. **交易条款的数字必须有推导链路。** 对赌业绩、回购利率、反投比例——每个数字必须写出"参照XX数据/按XX逻辑推算"，不得凭空给数字。严禁"建议对赌线8000万"而不说为什么是这个数字。
10. **"全国首创/唯一/领先/首发/率先"等自述必须与专利/认证清单交叉核验（操作化定义）。**
    - **核验数据源**：国家知识产权局专利检索系统（https://pss-system.cponline.cnipa.gov.cn，免费注册可查），辅以企查查/天眼查专利字段（后者仅作快速参考，不作为最终依据）
    - **专利口径**：仅统计"已授权且法律状态有效"的**发明专利**（不含实用新型、外观设计、软件著作权）
    - **自述关键词清单**（含语义等价词，防止绕过）：首创、唯一、领先、首发、率先、突破性、颠覆性、行业标杆、填补空白、国内第一、全球首创、国际领先、独家、首创技术。BP中出现以上任一词汇均计入自述次数
    - **阈值触发规则**：BP自述上述关键词总次数 > 发明专利数量 × 2 → 触发"密度落差"标注；在正文公司研判部分明确写出"公司自述的'首创'密度与实际专利储备存在重大落差，是核心硬伤"
    - **阈值说明**：× 2 为行业经验值，非统计推导。若发明专利≥10项或企业处于硬科技赛道，可将倍数放宽至 × 3，但须在报告中注明调整理由
    - **举例**：发明专利3项 + BP自称首创10处 → 3×2=6 < 10 → 触发；发明专利5项 + BP自称首创8处 → 5×2=10 ≥ 8 → 不触发密度落差标注，但仍须逐项核验
    - **不得用"待核实"模糊处理**：核验动作必须执行并给出结论；若因时间有限无法逐一核验，应在P1缺失项中说明"BP首创自述与专利对应关系待逐项核实"

## A2. 快速否决通道（Fast Reject）

**设计目的**：何松每天只有1-2小时，80%的项目不值得深入。快速否决通道让明显不可投的项目在3分钟内给出"不投"结论，省下时间给真正值得分析的项目。

### 触发条件（满足任一即进入快速否决）

| 触发信号 | 典型表现 | 否决依据 |
|---------|---------|---------|
| **一票否决** | 失信被执行人、重大行政处罚未结、实控人被限制高消费、核心专利全部无效 | 铁律7：P0级信息缺失/风险 |
| **财务硬伤** | 连续两年营收下滑超50%、经营性现金流持续为负且无改善趋势、资产负债率>85% | 基本面不可逆恶化 |
| **国资合规红线** | 明股实债特征、变相保底承诺、资金来源违规、应进场未进场 | 铁律+国资合规六项 |
| **关联依赖** | 关联方营收/采购>60%且无合理论证 | 业务独立性缺失 |
| **首创落差** | BP自称首创>10处，发明专利0项 | 铁律10：核心硬伤 |

### 快速否决流程（2步，3分钟内完成）

**Step 1：快速扫描（1次搜索 + 材料速读）**
- 搜索：企业名 + "诉讼 处罚 失信"（只搜法律风险维度）
- 速读：材料中财务数据（营收趋势、现金流）、关联交易占比、自述关键词密度
- 判断：是否命中上表任一触发信号

**Step 2：输出快速否决短信**

```
董事长，关于XX企业，经初步了解，存在以下致命问题，建议不推进：  # 注意：此处"董事长"应替换为配置中的sms_addressee
1. [最致命问题，一句话]
2. [第二严重问题，一句话]
综上，该项目存在根本性缺陷，建议不再投入时间。如需了解详情我可补充。
以上情况，请董事长阅示。
```

**快速否决不做的事**：不写完整报告、不跑质量门禁、不生成docx、不深入分析行业。只给短信级结论+关键理由。

### 不触发快速否决时

项目无致命硬伤 → 进入标准8阶段流程（Section C→K）。
