# 数据置信度标准

## E. 数据置信度标准

### 四级置信度定义

| 等级 | 来源类型 | 说明格式 |
|------|---------|---------|
| **高** | 政府官方文件、法定审计报告（无保留意见）、工商登记信息、司法裁判文书、证监会/交易所文件、官方资质认定 | `[来源：XXXX（2023年）审计报告，置信度：高]` |
| **中** | 行业研究报告（艾瑞/36氪/头豹）、政府统计数据、权威媒体报道（财新/第一财经）、企业官网/公众号、VC/PE数据库（IT桔子/清科） | `[来源：艾瑞咨询《2024年XX行业报告》，置信度：中]` |
| **低** | 企业自述/BP、未经审计的内部资料、口头承诺、非权威媒体、投资机构宣传材料 | `[来源：企业BP（2026年），置信度：低，待核实]` |
| **缺失** | 无任何来源 | `[数据缺失，无法计算]` |

### 交叉验证规则

**财务数据矛盾**：
1. 审计报告 vs 企业自述 → 审计报告优先
2. 审计报告 vs 媒体报道 → 审计报告优先，媒体报道标注"待核实"
3. 企业自述 vs 媒体报道 → 影响估值/交易条款/结论的必须选主数据源并说明理由；仅为背景信息可并列披露标注口径差异

**非财务数据矛盾**：
1. 政府官网 vs 第三方平台 → 政府官网优先
2. 第三方平台之间矛盾 → 取较保守/较旧数据，标注"数据存在差异"
3. 企业自述 vs 第三方数据 → 关键决策数据必须选主数据源并说明理由；非关键背景数据可给两个版本

### 主数据源选择规则

当同一数据点存在多个版本时：
- **关键决策数据**（营收、净利润、毛利率、现金流、估值、客户集中度、订单金额、股权比例、诉讼处罚、专利有效性、融资条款、回购/对赌测算）：必须选定主数据源，另一版本作为差异说明。
- **背景描述数据**（品牌荣誉、非核心案例、媒体评价、行业泛化描述）：可并列披露，但不得作为估值和交易条款依据。

主数据源优先级：政府/监管/交易所文件 > 审计报告/合同/司法文书 > 官方资质/工商登记 > 权威行业报告/VC数据库 > 企业自述/BP > 非权威媒体/口头信息。

### 时效衰减规则

- **财务数据**：审计报告超过18个月 → 自动降一级置信度（高→中，中→低）。企业业务发生重大转型或并购时，转型前数据不受时效衰减保护，直接标注"转型前数据，参考价值有限"
- **行业数据**：行业报告超过24个月 → 标注"数据可能过时"，不影响置信度等级但须提醒读者
- **法律/工商数据**：诉讼、处罚、工商变更等信息不受时效衰减（历史事实不变），但须核实是否为最新状态
- **企业BP**：BP本身为低置信度，不适用时效衰减，直接按低处理
- **示例**：2024年审计报告（高），分析日期2026年6月 → 已超18个月 → 降为中置信度，标注 `[来源：XXXX（2024年）审计报告，已超18个月，置信度：中（时效降级）]`
