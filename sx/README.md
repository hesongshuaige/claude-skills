# 学习内容升级工坊（sx / learning-upgrade）

一句话介绍：**把"没讲透"的学习文章升级成"小白能看懂 + 专业可信 + 能落地"的版本** —— 4 步升级法 + 4 关键标记 + 5 段轻量版兜底，保留原文骨架，只补三类关键信息。

> **版本：** 1.0.0 | **最后更新：** 2026-06-04 | **适用平台：** Claude Code / Codex / OpenClaw / Hermes / Agents

## 🎯 核心特性

- 🔍 **4 步升级法** —— 扫描 → 分类 → 升级 → 自检，每步都有可勾选动作
- 🏷️ **4 关键标记** —— 故事开场 / 说白了 / 检查清单 / 专业小技巧，缺一不可
- 📏 **5 段轻量版** —— 原文信息量小时用，避免硬套 02 模板把短文注水
- 🚫 **8 条不适用阈值** —— < 500 字符、API 参考、用户要简短、纯翻译、已升级过的，宁可不升级也不要硬塞
- 🛡️ **5 条反例库** —— 故事错位 / 说白了不直白 / 检查清单流于形式 / 软化不足 / 段落失衡
- ✅ **8 项自查清单** —— 升级完跑一次，8 项必须全过
- 🧩 **3 个 references** —— `anti-patterns.md`（反例库）/ `audit-checklist.md`（自查）/ `upgrade-template.md`（5 段轻量版 + 02 升级版模板）

## 🗣️ 触发词

**核心触发**：`sx`、`升级教程`、`升级文章`、`讲透`、`大白话版`、`小白版`

**问题触发**：
- "这篇教程没讲透 / 看不懂 / 跳过太多"
- "小白看不懂 / 太专业了 / 术语太多"
- "专业性可疑 / 命令像占位符 / 不真实"
- "看完不知道怎么动手 / 没例子 / 太抽象"
- "把这篇升级成大白话版"
- "写给小白看的版本"

**输入类型（啥文章都能升级）**：
- 技术教程、框架文档、API 指南
- AI 工具使用手册（Codex、Claude、Cursor 等）
- 公众号技术文章、技术博客
- 飞书知识库页面、学习笔记
- 课程讲义、培训材料

## 🔄 4 步升级法

```
[1] 扫描    → 读原文，打"小白看不懂"5 类 + "专业性可疑"5 类标记
[2] 分类    → 大改 / 小改 / 轻量版（按原文信息量 + 不适用阈值）
[3] 升级    → 套对应模板（02 升级版 / 5 段轻量版 / 仅补"术语 + 说白了"）
[4] 自检    → 跑 8 项 checklist，全部通过才算交付
```

## 🏷️ 4 关键标记（必须出现）

| 标记 | 作用 | 缺失代价 |
|---|---|---|
| **故事开场** | 用场景/比喻引入，吸引小白读下去 | 读者第一屏就划走 |
| **说白了** | 把术语翻译成人话 | 永远卡在"门槛" |
| **检查清单** | 学完可勾选，明确"我学会了" | 不知道学到什么程度 |
| **专业小技巧** | 给熟手用的进阶提示，建立专业可信 | 熟手觉得"水" |

## 🚫 5 条不适用阈值（任一命中就跳过升级）

| # | 阈值 | 正确做法 |
|---|---|---|
| 1 | 原文 < 500 字符 | 原样保留，不套模板 |
| 2 | API 参考文档（参数表/错误码） | 只补"术语 + 说白了" |
| 3 | 用户说"我要简短的" | 5 段轻量版都不上 |
| 4 | 纯翻译任务 | 翻译就别改了 |
| 5 | 已按 02 模式写过的 | 跳过，再套一层会注水 |

## 💡 快速使用

对 AI Agent 说：

> "用 sx 帮我把下面这篇 Codex 教程升级成小白能看懂的版本，要保留命令的真实性"

Agent 会：
1. 扫描原文，标出小白类 5 类 + 专业类 5 类问题
2. 判断走大改 / 小改 / 轻量版（按 5 条不适用阈值）
3. 套对应模板，补 4 关键标记（故事开场/说白了/检查清单/专业小技巧）
4. 软化绝对化表达（"不许" → "不建议"）
5. 跑 8 项自查清单
6. 返回升级版

整个流程 10-15 分钟。
