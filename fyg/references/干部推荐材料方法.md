# 干部推荐材料方法

适用：换届推荐、提拔建议、岗位配备意见等向组织部门提交的人事书面材料。

## 核心原则

1. **从组织需要出发，不从个人需要出发。** 写“为什么需要配这个岗位”，不是“为什么这个人该升”。
2. **用组织部熟悉的语言体系。** 关键词：班子结构、治理完善、三重一大、党政协同、职务层级、综合统筹。
3. **必须有硬业绩。** 不能全是能力和性格描述，要有具体资源、项目、渠道、制度或成果。
4. **语气明确但不能太直白。** 推荐就是推荐，但不能写成量身定制或个人先进事迹。

## 标准结构

```text
标题：关于XX领导班子配备有关情况的报告（或：关于推荐XX人选的报告）
主送：中共XX区委组织部（或相应组织部门）

引言段：换届背景 + 公司定位 + 报告目的

一、配备XX的必要性
   （一）强化党的领导，补齐党建力量
   （二）完善法人治理，优化决策机制
   （三）匹配职务层级，提升对外协调效能

二、建议人选及考察情况
   （一）政治素质过硬，履历结构复合
   （二）担当意识强，讲政治顾大局
   （三）协调能力突出，资源整合有成效
   （四）实干精神强，具备统筹基础

三、请示
   恳请纳入考察范围。
```

## 推荐表达

- “有人干事、无名分担责”
- “经历结构和能力特点，与XX岗位所需具有较高匹配度”
- “恳请将XX同志纳入此次换届考察范围”

## 常见坑

1. 太直白：不要写成“某同志在干招商但职务不够”，容易显得量身定制。
2. 只写能力不写业绩：必须让组织部门看到具体干了什么。
3. 语气太软：不要全程“建议关注”“纳入视野”。
4. 语气太硬：不要写“请组织部予以批准”，应尊重组织程序。
5. 落款口径不分：口头汇报和正式行文的主体可能不同。
6. 词过大：副职不要用“主导”“开创”“重塑”等过大表述。

## 多稿融合

当用户提供多个 AI 版本或参考材料时：

1. 逐篇评估哪些点值得吸收、哪些有坑。
2. 每条素材先过政治安全检查：是否太直白、是否量身定制、词是否过大。
3. 以本方法的结构为骨架，其他素材为血肉。
4. 融合后检查整体基调一致，不能有拼接痕迹。

## 写作流程

1. 确认用途：口头汇报参考材料，还是正式提交的书面材料。
2. 确认落款口径：党支部名义、公司名义，还是公司+领导个人。
3. 确认公司定位和班子成员现状，不能写错现有职务。
4. 收集人选素材：完整履历、硬业绩、能力特点。
5. 按标准结构起草，通常控制在800-1000字。
6. 对照下方清单自查。

## ⚡ 交付前必检（Verification——写完后再逐项验收）

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | 从组织需要出发 | 读者知道为什么需要配这个岗位 |
| 2 | 有硬业绩 | 至少2-3个具体事实，不能全是性格描述 |
| 3 | 语气得当 | 不过软、不过硬、不显得量身定制 |
| 4 | 落款口径对 | 用途和行文主体已确认 |
| 5 | 职务信息无误 | 相关人员现有职务、班子现状准确 |
| 6 | 词不过大 | “主导”“开创”“重塑”等大词已替换 |
