# 会见企业发言方法

## 定位

用于投资方、招商方、合作方代表跟企业面对面讲话。它不是体制内汇报，也不是座谈交流，而是平等合作关系下的发言。

## ⚡ 写作中必守（Harness——动笔时遵守，不是写完再检查）

1. **动笔前必须确认了四种姿态。** 不问清楚立场就写稿，风险极高。科创债教训：中金主动找上门，写了"主动推进"被打回，写了"婉拒"也不对，最后确认是"中立摸情况"。
2. **拒绝场景必须用结论式，不给细节。** 给细节=给对方反驳空间。唯一验证标准：对方听完是死心走了，还是觉得再努力一下有戏？
3. **每条诉求都必须有态度+路径+边界。** 能说的说清楚怎么做，不能说的说清楚为什么不能，不承诺办不到的事。

## 写作前必确认：四种姿态（第一步！）

在动笔之前，必须向用户确认本次会见的立场/姿态。同一企业、同一事项，不同场景下的立场完全不同：

| 场景 | 姿态 | 特征表述 |
|------|------|---------|
| 我们主动找对方，想推 | 主动推进 | 「我们很重视这个合作，今天来是想当面交流推进细节」 |
| 对方主动找我们，我们可推可不推 | 中立摸情况 | 「今天来主要是摸清情况，提前做准备，如果下一步要推，能快速启动」 |
| 对方主动找我们，我们想推掉 | 婉拒/暂缓 | 用「时机未到」代替「项目不行」，不当场拒绝 |
| 投促局/区领导推荐项目但研判不达预期 | 礼节性会见 | 必须先跟推荐领导汇报达成一致，再约企业见面 |

## 核心策略

### 发言顺序决定姿态

| 顺序 | 策略 | 结构 |
|------|------|------|
| 对方先讲 | 作为回应者，先接住对方说的，再展开自己的内容 | 接住对方→回顾合作→回应诉求→提期望→收尾 |
| 你先讲 | 作为定调者，先定合作基调，再说具体事项 | 定调→回顾→表态→提出问题→留空间给对方回应 |

### 语气平视，互利视角

对方是企业，不是上级领导，也不是下级单位。投资方不等于甲方，合作方不等于乙方。语气要平视，既不高高在上，也不过度客气。

- 「我们投了5亿」可改成「5亿元合作框架全面落地」
- 「你需要我们的支持」可改成「我们一起来看后续怎么配合」
- 不说「我们给了你们很大支持」（避免施舍感）
- 不说「请贵公司多关照」（避免过度客气）

### 表态要具体，但承诺要设边界

- 能给的说清楚怎么给：谁对接、什么流程、多久响应
- 不能给的说清楚为什么不能：权限不够、政策边界、需要协调
- 核心原则：能给的主动给，超出权限的一起争取，不承诺办不到的事

### 高情商话术公式

每个问题按「先肯定 + 再提问 + 说明原因」三层包裹：

| 不要说 | 要说 |
|-------|------|
| 「公司赚不赚钱？」 | 「我们最关心企业的盈利能力，想请教一下利润情况」 |
| 「这估值怎么算的？」 | 「想请教一下，这个估值主要考虑了哪些因素」 |
| 「产值怎么落地？」 | 「这个我们很感兴趣，想具体请教一下操作方式」 |
| 「不投」 | 「回去汇报后再定」 |
| 「肯定投」 | 「我们很有兴趣，会积极推进」 |

### 包裹式提问法

问题来源必须是研判报告中的信息盲区或关键分歧点。每个问题按三层结构：

1. **过渡**：「正因为我们对这个项目感兴趣，所以有几个问题想真诚地请教……」
2. **提问**：用「想了解」「想请教」开头，不质问
3. **原因**：「问这个是因为我们需要评估XXX，这直接关系到XXX」

常见问题方向（根据实际情况选3-5个）：
- 盈利情况：「我们做投资的，最关心就是企业能不能赚钱……」
- 估值逻辑：「想请教一下，这个估值主要考虑了哪些因素？不同行业、不同阶段，估值逻辑不一样」
- 资金用途：「如果合作达成，这笔资金主要用在哪些方面？政府投资的钱，每一笔都要有明确去向」
- 产值落地：「这个我们很感兴趣，但想具体请教操作方式，产值落地涉及税务、工商、跨区域协调」

## 标准结构

### 对方先讲：回应者模式

```
一、开场回应
   接住对方刚才讲的内容，表达认同或补充。

二、回顾合作成果
   列2-3个实质性成果，用具体数字。

三、回应对方诉求
   每条诉求都给出态度、路径、边界。

四、提你的期望
   写成「我们一起可以做什么」，不要写成单向要求。

五、收尾表态
   明确谁对接、做什么、什么时候跟进。
```

### 你先讲：定调者模式

```
一、开场定调
   说明本次会见目的和对合作的总体判断。

二、回顾合作成果
   用具体数字说明合作不是空话。

三、你方态度与支持
   不等对方开口，先把能给的态度摆出来。

四、抛出话题
   提出想听对方回应的问题或新合作方向。

五、过渡给对方
   留空间让对方回应。
```

## 特殊场景：婉拒/暂缓

当公司已决定不推进项目时，有两条路可选：

### 结论式（推荐——让对方一次死心）

结构：先夸 → 直接说结论 → 给台阶。不给细节。

**开场肯定（30%篇幅）**：赛道有意思、团队不错、我们研究过，不是没看过。

**明确结论（30%篇幅）**：「经过综合研判，暂不符合我们当前的投资方向。」结论要简洁、不可反驳。**不给细节**——给细节=给对方反驳空间。

**制度原因（可选加，20%篇幅）**：
> 「国有资本的投资决策有它的硬约束。我们是区属国有企业，每一笔对外投资都要过投决会，要过审计，还有国有资产保值增值的要求。不是我们觉得项目好就能投，还要看条件是不是具备、程序是不是走得通。」

效果：把「我们不投」变成「制度不允许投」，责任不在个人。

**给台阶（20%篇幅）**：「如果将来条件具备了，或者行业发生了大的变化，可以再谈。但目前，综合评估下来，条件还不成熟。」口子要开，但不能开太大——不能说「您回去改改再来」。

### 提问式（不推荐——对方觉得还有戏）

先夸 → 问四个问题 → 再给台阶。对方可能逐条反驳、追问细节。只在还想留口子、需要更多信息时使用。

### 验证问题

用这一个问题检验稿子是否合格：
> 「对方听完会是什么感觉？是死心走了，还是觉得再努力一下还有戏？」

答案是前者，稿子才对。

### 拒绝核心原则

- **归因于「时机」而非「项目本身」**：「不是你们不行，是整个行业还在等黎明」
- **不给细节**：单一客户占比高→对方说马上上量了，你答不上来
- **不证明自己专业**：不需要证明懂这个行业，只需证明决定有依据
- **责任推给制度**：个人不背「不识货」的名

## 常见场景

| 场景 | 你的角色 | 核心策略 |
|------|---------|---------|
| 会见已投企业 | 投资方 | 回顾成果 + 回应拨付/政策诉求 + 提下一步期望 |
| 会见潜在招商目标 | 招商方 | 展示本地优势 + 说明能给的 + 试探落地意愿 |
| 会见合作方 | 合作方 | 总结合作成果 + 协调后续事项 + 探索新合作 |
| 会见政府/园区领导并带企业 | 牵线方 | 介绍企业价值 + 说明落地需求 + 推动政策匹配 |
| 婉拒/暂缓（已决定不推） | 投资方 | 结论式：先夸→结论→制度原因→台阶。不给细节 |
| 上级推荐项目但研判不达预期 | 投资方 | 先跟推荐领导汇报一致→礼节性会见→归因行业时机 |

## 国企场合禁忌

- 不当场承诺或拒绝
- 不说「投不投」，说「回去评估研究」
- 不说「太贵了」，说「需要评估一下合理性」
- 不打断对方发言
- 不表现出轻视或傲慢
- 不承诺收益，不暗示保本，不夸大投资业绩
- 不披露未公开项目、未确认基金安排
- 整体语气不卑不亢

## 语言风格

1. 短句多，长句少；每句话尽量控制在30字以内
2. 数字比形容词好：说「3栋楼」，不说「较大规模的载体」
3. 主动比被动好：说「我们来对接」，不说「这个问题会被解决」
4. 不用「高度重视」「大力支持」这类空话
5. 结尾要有记忆点：一句判断、一个承诺边界或一个下一步动作
6. 口语化但不随意，像领导现场说的话，不是念稿子

## ⚡ 交付前必检（Verification——写完后再逐项验收）

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | 姿态确认了吗 | 已向用户确认四种姿态中的哪一种 |
| 2 | 身份对了吗 | 投资方、招商方、合作方的语气姿态正确 |
| 3 | 回应诉求了吗 | 每条诉求都有态度、路径、边界 |
| 4 | 高情商话术用了吗 | 提问用「请教」包裹，说明了为什么要问 |
| 5 | 有具体数字吗 | 至少2-3个实质性数据或事实 |
| 6 | 承诺有边界吗 | 没有开空头支票，没有说「一定」「保证」 |
| 7 | 拒绝场景对吗 | 用的是结论式，不给细节，验证问题通过 |
| 8 | 收尾有下一步吗 | 谁对接、做什么、什么时候明确 |
| 9 | 像人说的吗 | 读出来顺口，不像套话，有记忆点 |
