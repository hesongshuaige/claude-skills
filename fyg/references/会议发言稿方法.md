# 会议发言稿方法

## 适用场景

- 上级组织（区纪委监委、区委组织部、区国资委等）召开专题座谈会，分管领导在交流环节从自身职能角度补充发言
- 区级/市级座谈会发言（纪检、组织人事、审计等主题）
- 集团内部汇报会发言
- 多家单位联合会议的交流发言

## ⚡ 写作中必守（Harness——动笔时遵守，不是写完再检查）

1. **三条做法每条必须有人名+有机制+有可验证结果。** 空泛表态等于没写。
2. **困惑段必须用"请教"包装，必须同时提出诉求。** 只抱怨不要资源=失分。
3. **开场必须明确"在谁的汇报基础上、从什么角度"。** 多企业座谈会必须回应所有董事长发言，不只提自己董事长一人。
4. **问题表述不越线。** 说问题只能说"教育形式单一""自身能力不足"这个层面。不能暴露具体违纪线索、不能甩锅客观条件、不能点名批评。

## 铁律零：写作前角色定位三步分析（动手前必须完成）

在动笔之前，回答三个问题：

### 1. 谁做了主报告？（定你的位置）
- 董事长/总经理已做整体汇报 → 你是"补充"，不是"重复"
- 开场第一句必须明确：在谁的汇报基础上、从什么角度补充
- **多企业座谈会**：如果多个集团董事长依次汇报，开场要回应**所有**董事长的发言，不能只提自己董事长
- 单企业公式：「在刚才[XX领导]的汇报基础上，我从[你的职能]角度，补充几点……」
- 多企业公式：「听了刚才几位董事长的汇报，很受启发。在[自己董事长]系统汇报的基础上，我从[你的职能]角度，补充几点……」

### 2. 你的职能和会议主题的交集是什么？（定你的内容）
- 找到分管职能与会议主题的交叉地带 → 这就是发言内容来源
- 例：会议主题=纪检监察队伍建设，职能=组织人事/绩效考核 → 交叉=人员配备、培训、考核联通

### 3. 全场谁最大？（定你的语气和对谁说话）
- 实质听众是坐在中间的上级领导，不是兄弟单位同仁
- 语气：专业、务实、谦虚，不卑不亢
- 可以提困惑/建议，但必须用「请教」「借这个场合」包装

## 铁律一：搞清发言顺序再动笔

发言顺序决定内容策略：

- **正式汇报**（议程首位）：全面覆盖，讲成绩+问题+对策
- **座谈交流**（汇报后的补充）：只讲汇报没覆盖的角度，切忌重复
- **互动讨论**（自由发言）：聚焦一个亮点或一个问题，不需要面面俱到

## 铁律二：读到别人的材料再写自己的

如果会议有多人发言，且能拿到其他人（特别是领导）的发言材料，必须先读再写：

1. 标记领导已覆盖的内容，自己的发言全部避开
2. 找领导没提或一笔带过的内容，作为重点切入角度
3. 领导讲宏观/战略，自己讲微观/执行；领导讲整体/成绩，自己讲困难/建议

## 铁律三：根据听众调整深度和措辞

| 听众 | 策略 | 禁忌 |
|------|------|------|
| 上级领导 | 说真问题但措辞可控，建议要有建设性且对方能推动 | 不能纯诉苦、不能只喊口号 |
| 平级同行 | 适度展示成绩，坦诚交流困难，互相学习 | 不能炫耀、不能踩别人 |
| 下级/本部门 | 明确要求、给出方法、提考核 | 不能空洞 |

## 座谈发言稿标准结构（三段式）

### 第一段：具体做法（占60%篇幅，3条）

每一条做法必须满足三个要求：

1. **做得实**：有可验证的具体动作，不是态度表态
2. **有人名**：点到具体负责执行的同志（展示「这事真有人在做」）
3. **有机制**：描述的不是一次性动作，而是运转中的机制/流程

格式：
```
第X，在[方面]上，[具体做法]。我们目前的[机制/制度]里，[具体描述]。
具体[执行/操作]上，[点名+职责]，做到[可验证的结果]。
```

### 第二段：困惑与建议（占25%篇幅，1条）

**核心原则：把诉求包装成请教，把争取资源包装成试点意愿。**

结构：
1. 说困惑：描述一个真实的、同行也有共鸣的困难
2. 引用一线声音：「我们有同事跟我讲……」（增加说服力）
3. 提建议：不是直接要资源，是「能不能考虑……我们愿意做试点」
4. 留钩子：让对方觉得这是可以做、但需要你配合的事

### 第三段：表态收尾（占15%篇幅）

- 概括你的职能如何继续支持会议主题
- 三个动词收束：配强、做实、联通（根据主题调整）
- 最后：「以上是我的发言，不当之处请[最高领导职务]和各位领导批评指正」

## 多企业座谈会特殊处理

当会议是多个集团董事长依次汇报的座谈会（如区纪委监委召集4家国企），注意：

- 开场必须回应所有董事长的发言：「听了刚才几位董事长的汇报，很受启发」
- 不能只提自己董事长一人——这会被理解为只关心自家
- 找到跨企业的共性话题作为切入点（如「几家集团都提到了复合型人才稀缺的问题」）

## 常见角色与角度

| 角色 | 推荐切入角度 | 避免踩的坑 |
|------|-------------|-----------|
| 一把手/主要负责人 | 主体责任+整体情况+方向性判断 | 不能太具体到某个部门的事 |
| 分管领导（人事/综合/党建） | 组织人事+内部协同+执行感受 | 不能重复一把手已说的内容 |
| 分管领导（业务/项目） | 项目推进+行业判断+业务风险 | 不能只谈业务不谈政治/合规 |
| 分管领导（财务/后勤） | 资源保障+资金效率+降本增效 | 不能只列数字不谈管理 |
| 部门负责人 | 本部门工作+基层困难+团队状态 | 不能越级谈单位战略 |
| 基层干部/业务骨干 | 一线执行体验+具体案例+实操建议 | 不能空谈理论、不能抱怨领导 |

## 常见座谈会类型与何松的切入点

| 座谈主题 | 切入点 |
|---------|--------|
| 纪检监察队伍建设 | 组织人事/人员配备 + 绩效考核/廉政指标 + 培训/能力建设。⚠️ 投资类国企特殊性：纪检干部需兼具纪检+投资业务能力，建议段可提「复合型人才稀缺」，请求区纪委开展针对投资场景的专项案例教学（尽调/对赌/VIE架构中的廉洁风险识别） |
| 招商引资/产业发展 | 招商工作+投资项目研判+绩效考核驱动 |
| 国企改革/公司治理 | 组织架构+人力资源+财务管控 |
| 党建工作 | 组织人事+考核评价+培训体系 |

## 政治敏感度要点

1. 「说问题」不等于「暴露问题」：教育形式单一可以讲，具体违纪线索不能在会上讲
2. 建议要有归口：纪律培训找纪委，编制问题找组织部，资金问题找财政局
3. 资源有限单位的「弱」要讲成「自身能力不足」：不说客观条件制约，改说专业能力、精细化管理还有差距
4. 数据必须真实：人数、次数、问题数必须和正式报告一致

## 语言风格

- 从个人表态、切身感受、实际工作出发，不写成分析报告
- 不点名领导，用「各家兄弟单位」代替具体人名
- 不举自身负面例子，用正面表述带出事实
- 表态要具体，不说「高度重视」，说「我会盯住XX」
- 短句多，长句少；每句话尽量控制在30字以内
- 通篇用「我们」，不抢董事长风头，不越位

## ⚡ 交付前必检（Verification——写完后再逐项验收）

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | 角色定位做了吗 | 开场明确了「在谁的基础上、从什么角度」，多企业座谈会回应了所有董事长 |
| 2 | 三条做法合格吗 | 每条有具体动作、有人名、有机制，不是空泛表态 |
| 3 | 困惑段有诉求吗 | 用「请教」语气，同时提出了具体诉求或试点意愿 |
| 4 | 场景对了吗 | 座谈、汇报、讨论的语气和结构匹配 |
| 5 | 避开别人了吗 | 没有重复主报告内容，讲了别人没讲的角度 |
| 6 | 措辞安全吗 | 没有自我揭短、点名批评、甩锅客观条件、越位表态 |
| 7 | 篇幅合适吗 | 5分钟以内（800-1200字） |
| 8 | 像人说的吗 | 读出来顺口，短句多，收尾有明确表态或下一步 |
